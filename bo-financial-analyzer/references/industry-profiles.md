# 行业 / 商业模式画像（industry-profiles）

> 本手册供 **Phase 2 开头**使用——先识别商业模式，加载对应 profile，再进入四维比率（frameworks.md）。
> 没有这一步，redflags.md 的阈值就是「一套框架打天下」：工程建造的完工百分比、渠道零售的压货、
> 农业的生物资产盘点，勾稽重点与雷型完全不同，用同一把尺子会**同时误报**（把行业属性判成雷）与
> **漏报**（该模式的核弹级线索没进勾稽清单）。
> 定位：本手册决定**用哪把尺子去量**——只调整「阈值 × 勾稽异常 × 行业模式」三维中的
> **模式轴**（Phase 3 判定升级为三维，模式轴此前无落点）；定级仍服从三态 🟢/🟡/🔴。

## 识别流程（Phase 2 起始动作）

1. 读「营业收入确认政策」+ 资产结构（固定资产/在建工程/合同资产/生物资产 ÷ 总资产）
   → 从速查表选**主模式**（兼类公司取收入占比最大的，另一类作为补充 profile 并列声明）
2. 把该模式的「重点勾稽」写成报告的**本报告重点勾稽项**；把「应降级的通用信号」列出并说明降级理由
3. 渠道零售 / To G → 第二部分客户价值五维判读必做；渠道零售另做第三部分压货三条件
4. 识别结论写成一句话，落进报告核心结论区（话术模板见第四部分）
5. **无法归入八类时**声明「通用框架」并说明理由，下期跟踪清单改用**通用缺省集**：
   合同负债剪刀差 + 资本开支节奏 + 按资产结构补 2 项（应收 / 存货 / 在建工程中占比最大的那类）
6. **下期跟踪清单（Phase 8）**：从该模式「先行指标建议集」里选 3~5 项，每项写成
   条件化触发线（if-then，「若 X 连续两期……则 Y 成立」），落进 data.json 的 `watchlist` 块

## 一、八类商业模式速查表

| 模式 | 重点勾稽 | 特有雷型 | 应降级的通用信号 |
|---|---|---|---|
| 工程建造 | 合同资产/合同结算、完工进度 vs 现金回款（A4 / B1 / B3） | 完工百分比激进、已完工未结算资产挂账 | 存货高企（多为已完工未结算）、应收（业主结算周期长） |
| 渠道零售 | 合同负债、返利计提、存货结构（A4 / B2 / B1） | 经销商压货、期后退货、返利挂账 | 应收账款（现款现货模式下基数天然小） |
| To G | 应收账龄（政府客户）、回款周期（B1 / A4） | 应收永续挂账、PPP 出表 | 净现比（财政付款周期长属常态） |
| 软件订阅 | 递延收入/合同负债先行指标、ARR 口径（A4 / A3） | 收入确认口径切换、研发资本化激进 | 预收/合同负债高（商业模式使然，非风险） |
| 农业养殖 | 生物资产盘点、消耗性/生产性划分（B2） | 盘点不可验证（獐子岛型） | 存货周转（生长周期决定） |
| 资源周期 | 成本曲线、资本开支周期（A6 / A5） | 逆周期扩张失血 | 毛利率波动（随商品价格，属周期属性） |
| 重资产制造 | 转固节奏、折旧政策、Capex 勾稽 A6（A5 / B3） | 折旧年限延长、在建不转固 | 高 Capex（重资产属性） |
| 医药健康 | 研发资本化率、license-out 确认节奏、集采暴露度、销售费用率 | 研发资本化美化利润、license-out 一次性收入冲击、集采降价后收入失速 | 存货总量（原料药安全库存）、在建工程（轻资产创新药）、合同负债水平（医院/渠道占款） |

### 1. 工程建造（建筑 / 装饰 / 园林 / 环保工程 / 设备成套）

- **识别特征**：收入确认政策含「履约进度」「完工百分比」「投入法 / 产出法」（Grep 营收确认政策节）；
  资产端出现「合同资产」「合同结算」科目，金额常 > 收入的 20%；经营现金流 ÷ 收入长期 < 0.8
- **重点勾稽**：A4 收入-收现闭环（连续 2~3 年同向缺口才是结构性信号，单年不作为结论）；
  B1 应收 roll-forward；**合同资产 = 已完工未结算**，schema 无独立字段，须从资产负债表/附注手工取
  并写进 `recon.A4_rev_cash.src`；完工进度与收入增速的联动（进度数据在附注「合同资产」明细）
- **特有雷型**：完工百分比激进（提前按投入法确认收入）；合同资产/GMI 矛盾（已完工未结算挂账不结算
  也不减值）；把应收账款与合同资产的划分当调节池（先挂合同资产、结算后再转应收，推迟坏账计提）
- **先行指标建议集（下期跟踪清单取用，3~5 项）**：
  ① 合同负债/预收与收入的剪刀差（连续两期低于收入增速 → 新签订单走弱）
  ② 应收账龄迁移率（1 年内 → 1~2 年迁移加速 = 结算与回款同时恶化）
  ③ 垫资节奏：「合同资产 + 应收」÷ 收入 与 OCF ÷ 收入的相对变化（垫资变重而回款未改善）
  ④ 新签订单 / 中标公告金额（早于报表，公开可查）

### 2. 渠道零售（食品饮料 / 服饰 / 家电 / 日化 / 医药流通）

- **识别特征**：收入确认「交付 / 发出商品时确认」（非终端销售确认）；应收账款极小（现款现货）而
  `statements.balance.contract_liab` 大；销售费用率 10%~30%；`notes.inventory_mix` 以库存商品为主；
  年报「销售模式 / 经销商」节披露经销商数量
- **重点勾稽**：A4（**Δ合同负债必须保留**，articulation B1 已强调，漏掉预收模式必然不平）；
  B2 存货 roll-forward 看库存商品占比与跌价准备率；第三部分压货三条件
- **特有雷型**：经销商压货（收入前置、渠道库存高企）；期后退货（查 `notes.subsequent_events`）；
  返利挂账（「应付返利」藏在其他应付款 / 合同负债，返利计提率下降 = 少计费用推高毛利）
- **先行指标建议集（3~5 项）**：
  ① 合同负债（经销商打款意愿）与收入增速的剪刀差
  ② 存货周转天数 / 渠道库存（经销商库存、批价或终端动销）
  ③ 应收增速 − 收入增速（信用政策是否放松）
  ④ 次期季报收入同比（压货验证的决定性条件，见第三部分）

### 3. To G（智慧城市 / 环保 / 军工 / 系统集成 / 医疗信息化）

- **识别特征**：前五大客户以政府部门/国企为主且 `前五大占比 > 50%`（年报「前五名客户」附注）；
  应收账龄 1~2 年占比大（`notes.ar_aging`）；净现比长期 < 0.7
- **重点勾稽**：B1 应收 roll-forward + 账龄迁移；A4；第二部分客户价值五维判读必做
- **特有雷型**：应收永续挂账（政府客户不坏账但也不回款，账龄迁移率固化）；PPP / BOT 出表
  （长期应收款、其他非流动金融资产，看附注是否重分类）
- **先行指标建议集（3~5 项）**：
  ① 回款周期：收现比（销售商品收到的现金 ÷ 营业收入）趋势
  ② 应收增速与账龄结构（1~2 年占比是否固化）
  ③ 合同负债/预收变化（在手订单的先行读数）
  ④ 地方财政 / 专项债与行业招投标数据（外部观察哨）

### 4. 软件订阅

- **识别特征**：收入确认政策含「在授权期间 / 服务期间分期确认」「SaaS / 订阅」；
  `contract_liab ÷ revenue > 20%` 且逐年上升；研发资本化金额较大；应收账款小
- **重点勾稽**：A4（Δ合同负债是**收入先行指标**，不是风险项，方向比水平重要）；
  A3 间接法调节桥（研发资本化的现金已在经营或投资段流出，与利润不匹配）
- **特有雷型**：收入确认口径切换（一次性授权 ↔ 分期订阅，切换当年收入跳变需单独还原）；
  研发资本化激进（redflags 黄色表阈值 30%，配合「无形资产本期摊销 vs 资本化金额」看是否只增不减）
- **先行指标建议集（3~5 项）**：
  ① 递延收入/合同负债余额与增速（先行于收入一到两个季度）
  ② NRR 替代项：存量客户收入留存率（未披露时用「合同负债 ÷ 收入」+ 续费/续约公告替代，
     并注明口径近似）
  ③ 预收 / 合同负债 ÷ 收入的边际变化
  ④ 研发资本化率（口径切换的前兆）

### 5. 农业养殖（畜牧 / 水产 / 种植 / 种业）

- **识别特征**：资产负债表单列「消耗性生物资产」「生产性生物资产」；`notes.audit.kam` 提及
  存货监盘 / 生物资产（KAM 是否把生物资产列为关键审计事项是重要线索）；存货周转天数以年计
- **重点勾稽**：B2 存货 roll-forward（生物资产常无「本期增加额」披露 → 按 articulation B2 降级为
  方向性联合校验，**不硬凑**）；`notes.capacity`（存栏/出栏/面积）；盘点可验证性
- **特有雷型**：盘点不可验证（獐子岛型——底播扇贝/深海鱼无法核数）；消耗性 ↔ 生产性生物资产
  划分调节（生产性不提减值、折旧年限拉长）；单价假设（农产品公允价值模型参数不可验证）
- **先行指标建议集（3~5 项）**：
  ① 存栏 / 出栏（或养殖面积）与产能公告
  ② 主原料价格（玉米/豆粕等，mx_macro_data）
  ③ 产品价格（生猪/水产/原粮现货价）
  ④ 生物资产余额与结构（消耗性 vs 生产性划分变化）

### 6. 资源周期（煤炭 / 有色 / 钢铁 / 化工 / 锂电材料 / 建材）

- **识别特征**：产品为大宗商品，价格可外部取得；毛利率年度波动 > 15pct；固定资产 + 在建工程
  ÷ 总资产高；成本端原材料 / 能源占比高
- **重点勾稽**：A6 Capex 勾稽（逆周期扩张的资金压力）；A5 隐含折旧率对照同业；
  B3 在建工程 roll-forward；成本曲线分位用 `mx_macro_data` 商品价格 + 同行成本数据
- **特有雷型**：逆周期扩张失血（capex 高峰撞上价格下行，OCF 覆盖不了 capex + 利息）；
  成本曲线右端（高成本产能，价格跌破现金成本线即亏损）；存货/高价原料库存减值滞后
- **先行指标建议集（3~5 项）**：
  ① 大宗商品价格 × DIO 传导状态（价已涨而 DIO 未拉长 → 成本尚未进表，毛利压力在后；
     价跌 + DIO 高企 → 减值风险）
  ② 资本开支节奏（连续两期收缩 = 转保守；逆势扩张要追问钱从哪来、产能谁来消化）
  ③ 库存商品/原材料结构与跌价准备率
  ④ 行业开工率 / 产能投放进度（外部数据）

### 7. 重资产制造（汽车零部件 / 机械 / 面板 / 半导体 / 水泥）

- **识别特征**：（固定资产 + 在建工程）÷ 总资产 > 40%；折旧 ÷ 收入 > 8%；
  `capex ÷ dep_amort` 持续 > 1.5；扩产依赖在建工程
- **重点勾稽**：A5 折旧摊销勾稽（补算 `dep_amort ÷ avg(固定资产原值 + 使用权资产)` 得隐含折旧率，
  与同业 5%~10% 对照）；A6 Capex；B3 转固节奏
- **特有雷型**：折旧年限延长（会计估计变更，量化 Δ折旧 = 原值 × (1/旧年限 − 1/新年限)）；
  在建不转固（`notes.cip_projects[].progress ≥ 90%` 而 `transferred = 0`，redflags #8）
- **先行指标建议集（3~5 项，即通用缺省集）**：
  ① 合同负债增速 vs 收入增速（剪刀差）
  ② 存货形态结构（原材料/在产品占比变化 = 备产或堆积）
  ③ 产能利用率 / 开工率
  ④ 资本开支节奏（购建固定资产等支付的现金）
  ⑤ 大宗价格与 DIO 传导状态（原料占成本比高时必看）

### 8. 医药健康（创新药 / 仿制药 / license-out 平台）

- **画像一句话**：创新药（研发管线驱动）+ 仿制药（制造/渠道）+ 对外许可
  （license-out 类平台收益）混合模式，单类无法覆盖
- **识别特征（典型收入结构与利润驱动）**：收入三段式——创新药收入（新药放量驱动，毛利
  最高）、仿制药收入（集采中标降价与销量对冲，制造/渠道逻辑）、license-out 首付款/里程碑款
  （一次性、不连续，直接扰动当期收入与预收/合同负债）；利润驱动以创新药毛利 + 平台分成
  为主，研发费用的费用化/资本化政策对利润的影响远大于其他模式
- **收入轴声明（分部桥分组轴，v0.0.7）**：创新药 / 仿制药 / license-out（对外许可）——
  与画像的「收入三段式」识别特征及先行指标建议集 ①③ 同构；医学科室/治疗领域轴只作
  结构升级证据（分产品毛利率），不作收入桥主轴
- **重点勾稽（核心勾稽项）**：研发资本化率（资本化研发 ÷ 研发投入合计，注意与利润表
  「研发费用」口径区分）；license-out 首付款/里程碑确认节奏（一次性款项计入当期收入时
  对收入与预收/合同负债的扰动，须单列还原，避免误判收入异动）；集采暴露度（集采品种
  收入占比）；销售费用率与合规（学术推广/佣金模式，费用率异常波动是合规风险的先行读数）
- **调焦阈值**：研发资本化率 > 30% 关注（沿用 redflags 黄色表阈值）；销售费用率异常波动
  （偏离同业常态区间须追问）；单一集采品种收入占比过高等（高暴露品种的中标价降幅
  直接映射下期收入与毛利率）
- **降级信号**：存货总量信号（原料药/中间体安全库存企业，属主动经营，转结构判读）；
  在建工程信号（轻资产创新药主体，Capex 本就不是核心变量）；合同负债水平信号
  （医院/渠道占款模式，水平高低不判风险）——参照恒瑞医药 2026H1 报告的调焦声明实践
- **先行指标建议集（3~5 项）**：
  ① 创新药收入占比及增速（`by_segment` 分部/产品口径 + 年报产品披露）
  ② 管线里程碑达成数（临床进展公告，早于报表）
  ③ license-out 签约额（公告首付款/里程碑条款）
  ④ 集采中标价降幅（带量采购公告，映射下期收入）
  ⑤ 应收账款 DSO（医院回款周期）

## 二、客户价值五维判读（渠道零售 / To G 必做）

联合判定维度：**客户集中度 × 毛利率 × 回款（DSO）× 费用归属 × 增长贡献**。

**数据限制与近似口径（必须在报告标注）**：A股年报强制披露「前五名客户销售额占年度销售总额
比例」，但绝大多数**不披露单客户收入与毛利**。五维无法直接计算时，用
`集中度 × 分部毛利率（statements.income.by_segment[].rev_cur/cost_cur）× 整体 DSO` 近似
（前提是客户集中于某分部），**报告中必须标注「口径近似」**，不得当作精确值下结论。

### 五维判读规则

| 维度 | 数据源 | 判读阈值 | 结论 |
|---|---|---|---|
| ① 客户集中度 | 年报「前五名客户」附注（**schema 暂无字段**，暂记 `signals[].data`） | 前五大占比 > 50% → 🟡；> 70% → 高 | 大客户依赖，看变化方向而非绝对值 |
| ② 毛利率 | `by_segment` 分产品/分部毛利率 | 大客户所在分部毛利率 − 其他分部 > 10pct | 高毛利客户需有产品差异的硬解释，否则可疑 |
| ③ 回款 DSO | `derived.ratios.dso.cur − prev` | DSO 同比 +20 天以上 | 议价力弱 / 信用政策放松 |
| ④ 费用归属 | 销售费用明细分项（运费/服务费/返利） | 销售费用率同比降 > 3pct 而收入增 | 大客户承担推广（毛利虚高）或费用挂账 |
| ⑤ 增长贡献 | `by_segment` 分部收入增量 | 单分部贡献 Δ收入 > 50% 且该分部客户集中 | 增长单点依赖，质量打折 |

### 判读矩阵（客户集中度 × DSO）

| 集中度 \ DSO | 收窄（↓） | 基本持平（±10 天） | 拉长（↑ > 20 天） |
|---|---|---|---|
| 低（< 30%） | 分散优质 🟢 | 正常 | 行业账期延长或信用放松 🟡 |
| 中（30%~50%） | 健康 🟢 | 正常 | 议价力弱 🟡 |
| 高（> 50%） | 依赖但回款可控 🟡 | 大客户账期刚性 🟡 | **议价力弱 + 关联嫌疑 🔴** |

### 关联方伪装嫌疑（判定规则）

**大客户毛利率显著高于整体（> 10pct）且客户身份模糊 = 关联方伪装嫌疑 → 🔴**，
「身份模糊」指同时命中以下任一：非上市 / 非知名、成立不足 3 年、注册资本小于交易额、
注册地址与公司同址或同园区、年报未披露客户名称只有「客户一」。
配套查证：其他应收款（redflags #6）、预付账款对象、`notes.shareholders.top10_changes`。
联动触发：redflags 黄色表「关联交易占比高」（关联销售/采购 > 20%）与「客户/供应商集中」
（前五大 > 50%）两条同时命中即升级。

## 三、经销商压货三条件勾稽（渠道零售必做）

三条件（**三条件齐备才判压货 🔴；仅两条 = 观察项 🟡；仅一条不立案**）：

| # | 条件 | 判据与阈值 | 数据源 |
|---|---|---|---|
| ① | 经销商渠道收入激增 | 该渠道/分部收入增速 > 30% **且** 高于整体收入增速 15pct+ | `statements.income.by_segment[].rev_cur` / `rev_prev`、年报「销售模式」节 |
| ② | 合同负债 / 应收同期异动 | 合同负债同比降 > 15% 而收入仍增（渠道打款意愿下降）；**或**应收增速 − 收入增速 > 20pct | `statements.balance.contract_liab` / `ar`；redflags 黄色表 + #4 维度一 |
| ③ | 次期收入回落 | 次期季报/半年报收入同比 < 0 或增速较本期腰斩（降幅 > 50%） | tushare `income`（`period` 取次期报告期，如 `20260331`）、`fina_indicator.or_yoy` |

**第 ③ 条的验证方法（本条是压货判定的决定性条件，也是时点难点）**：

1. 年报（次年 3~4 月）发布时，次年 Q1 报（4 月底）常尚未出 → 先用 tushare `income` /
   `fina_indicator` 按期次取数；不可得则用 mx `mx_finance_search_notice` 查季报原文，
   仍不可得时改用外部信号（渠道库存 / 批价 / 经销商调研）
2. **无法验证第 ③ 条时，①②成立也只判 🟡**，并在报告写明「压货迹象未获次期验证」，
   禁止凭两个条件直接判 🔴
3. 例外排除（三条都要过）：季节性行业用同比而非环比（Q1 淡季）；渠道改革期区分主动去库存；
   并表范围变动带来的收入基数变化

判定落库：三条件齐备 → `signals` 新增一条（`level = "r"`，`title` 写「经销商压货三条件齐备」，
`data` 写三条的实测值，`source` 写出处）；仅两条 → `level = "y"`。
