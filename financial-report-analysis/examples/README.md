# examples/ — 标杆样本（few-shot 参考）

`标杆样本-贵州茅台-600519-年报-2025FY.html` 是一份已渲染验证过的完整报告，
取自 `reports/贵州茅台-600519-年报-2025FY-20260904.html`（46 KB）。

## 它的作用

写新报告时把它当**行文与填充质量的参照**，看四件事：

- **槽位怎么填**：`{{占位符}}` 该给一句话还是给数字，表格单元格填到什么粒度
- **文字密度**：每段解读多长、结论先行还是证据先行、表格前后要不要配一句话
- **出处怎么写**：正文卡片右下角的「出处：…」与表格 `srcline` 的具体写法（章节/附注编号精确到条）
- **信号与桥的叙事**：颜色徽章的判定措辞、桥的图注怎么把数字翻译成人话

## 重要提醒：它是 P0 改造**之前**产出的

本样本的章节骨架（00 核心结论 → 07 外部校验，共 8 节）与当前模板一致，但**不含**
P0 之后新增的槽位。新报告一律按 `assets/report-template.html` 产出，本样本**只作行文与
填充质量的参考**；不要照抄它的结构。
