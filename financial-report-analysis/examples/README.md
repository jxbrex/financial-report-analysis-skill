## 它的作用

写新报告时把它当**行文与填充质量的参照**，看四件事：

- **槽位怎么填**：`{{占位符}}` 该给一句话还是给数字，表格单元格填到什么粒度
- **文字密度**：每段解读多长、结论先行还是证据先行、表格前后要不要配一句话
- **出处怎么写**：正文卡片右下角的「出处：…」与表格 `srcline` 的具体写法（章节/附注编号精确到条）
- **信号与桥的叙事**：颜色徽章的判定措辞、桥的图注怎么把数字翻译成人话

## 参照时的边界

- 它是**半年报 + 化险期地产**样本：连亏负值柱、破产双模型「危险」、扣非双版触发、
  双驱动护栏命中都是异常形态的真实示例——危机叙事的密度是它的个例，不是常态模板
- 年报专属槽位（Q4 单季透视/股东户数/机构预期全年口径）在半年报形态下降级呈现；
  年报样本待首份现行模板年报产出后补充
- 结构永远以 `assets/report-template.html` 注释为准；样本与模板冲突时以模板为准
