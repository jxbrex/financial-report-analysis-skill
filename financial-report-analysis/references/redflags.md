# 排雷信号库（redflags）

> 用法：Phase 3 逐条对照。每条信号给出**判定阈值、证据来源、常见合理解释**。
> 有合理解释的降级为 🟡 观察项，没有才列 🔴 风险。所有判定必须附报告出处。

## 〇、判定分类（四态，所有信号共用）

阈值是入口，不是结论。每条信号对照阈值后落入四态之一，报告层据此决定「展开还是汇总」。
**报告 = 沟通物，正文只承载有动作价值的条目：排雷的动作重要，不是雷的东西不列**
（修订计划 v0.2.0 定案）。

| 四态 | 标准 | 报告呈现 | `level` |
|---|---|---|---|
| 🔴 **命中** | 达到阈值且排除合理解释（现行标准不变） | **逐条展开（唯一展开层）** | `r` |
| 🟡 **观察** | ① 达到阈值但存在部分合理解释；或 ② 未达阈值但**方向 × 速度异常**（如账龄迁移加速、DSO 连续两期走高） | **两行形态（担心 → 本案）**：担心 = 这信号若是真雷，经营上意味着什么（三问①）；本案 = 最可能的经营解释 + 区分证据（三问②），**上限 6 条**，超出并入表末汇总 | `y` |
| ↩ **反向未触发** | 信号反向成立且**含信息量**（如非经常性损益为反向拖累——扣非 > 归母；合同负债逆势大增） | **不再有可见行**，与未触发一并压入表末 total 汇总行 | `g` |
| ⚪ **未触发** | 数字有波动但结论正常 | 与反向一并压入表末 total 汇总行 | `g` |

- **表末 total 汇总行**（反向 + 未触发的唯一载体）：一行给出四计数——
  「命中 x · 观察 y · 反向 z 组 · 未触发 w」，并附指引「逐条读数与出处见 data.json signals 块」
- 「反向未触发」与「未触发」都记 `level = g`，区别在**信息量**：前者是与风险方向相反的
  正面读数，落进底稿能说明「这条雷确实不存在，且证据在反方向」；后者只是无事发生
- 反向与未触发的逐条读数与出处**仍要落** data.json 的 `signals` 块——完整性由底稿承担，
  报告正文只承载有动作价值的条目
- **勾稽异常表**：只列 ⚠️/🔴 两态，✅ 闭合项一行带过（闭合不是问题，不占正文）
- 四态是**呈现分类**，不改动信号本身的定级规则；升级/降级（阈值 × 勾稽 × 行业模式）
  仍按本文件与 industry-profiles.md 执行
- **机检兜底**：check_html 对「反向可见行 > 0」「未触发逐条行 > 1」「观察行 > 6」报 WARN

## 一、经营背离信号（原「红色信号」）

> 背离 = 数字与「正常经营该有的样子」不一致。定位是**理解经营的入口**，不是定罪清单：
> 比率类异常只能给「需观察 + 经营解释」，硬证据（勾稽不平/审计非标/独董异议/问询函/
> 期后违约）才可下重话（HANDOFF v0.3.0 定案）。

**三问范式（所有信号的判定语必须照此落地）**——每条异常必须回答：

1. **经营上发生了什么**（这个数字说明什么经营事实，一句话）
2. **最可能的经营解释 + 区分证据**（禁止并列可能性、禁止「属正常波动」式空话——
   写不出区分证据 = 分析没做完；空话清单与标准回应见第四节反驳表）
3. **下期看什么验证**（哪个先行指标能证实/证伪，候选进 watchlist）

### 1. 存贷双高 ★康美/康得新式
- **判定**：货币资金 ÷ 总资产 > 25% **且** 有息负债 ÷ 总资产 > 20%
- **发生了什么**：公司一边囤着大把现金、一边付高息借钱——正常经营不会做这种亏本买卖
- **最可能解释 + 区分**：最可能是货币资金受限/被归集/虚构。区分证据：货币资金附注「受限」
  明细、利息收入 ÷ 平均货币资金（<1% 指向资金不在账）、是否有集团财务公司归集协议
- **下期验证**：受限资金占比变化、利息收入率、短债续贷公告
- **出处**：资产负债表 + 货币资金附注（看「受限资金」明细）

### 2. 利息收入与货币资金不匹配
- **判定**：利息收入 ÷ 平均货币资金 < 1%（连活期利率都达不到）
- **发生了什么**：账上资金产生的利息连活期利率都跑不赢
- **最可能解释 + 区分**：最可能是资金大部分时间不在账上（期末冲回）。区分证据：利息收入率
  vs 当期活期/协定存款利率；各季报货币资金均值 vs 年末值（年末异常冲高 = 冲回痕迹）
- **下期验证**：利息收入率是否回到利率中枢、季报货币资金稳定性
- **出处**：利润表财务费用附注中的利息收入

### 3. 净现比长期异常
- **判定**：经营现金流净额 ÷ 归母净利润 连续 2 年以上 < 0.5
  （口径统一用归母；少数股东损益占比大时两个口径并列出示，差异本身也是信息）
- **发生了什么**：利润是纸面的，现金没跟上——利润含金量不足
- **最可能解释 + 区分**：最可能是营运资本吞噬（钱压在应收/存货里）。区分证据：OCF 调节桥
  找吞噬去向；收现比 < 0.9 = 收入含「白条」。例外：高速扩张期前置投入——须管理层解释
  且资本开支/研发落点可指认，指认不出不采信
- **下期验证**：净现比是否回到 0.5 上方、应收/存货增速是否收敛

### 4. 应收账款异常（三维判定）
- **维度一·增速差**：应收账款增速 − 收入增速 > 20 个百分点（Beneish DSRI 思路）
- **维度二·账龄恶化**：连续两期账龄表对比迁移率（1年内→1~2年、1~2年→2~3年），
  迁移加速 = 回款质量下降（操作见 articulation.md B1、年报应收附注账龄表）
- **维度三·计提变化**：分账龄段计提比例下调（会计估计变更，量化利润影响）；
  **当年核销 > 当年计提 = 长期计提不足铁证**（数据：notes.ar_provision.charged/reversed + ar_writeoff）
- **发生了什么**：收入在「打白条」——账面收入涨了，钱没收到
- **最可能解释 + 区分**：最可能是压货冲收入或放松信用政策。区分证据：账龄迁移加速 = 真恶化；
  计提比例下调 + 当年核销 > 当年计提 = 长期计提不足；应收票据+应收款项融资占比高 = 相对优质
- **下期验证**：期后回款（次期 OCF / 收现比）、账龄迁移率
- **定级**：单维触阈值 → 🟡；两维同向 → 🔴；三维齐中 + 行业模式吻合（如工程建造）→ 高危 🔴
- **小基数陷阱**：先款后货型公司（白酒等）应收仅百万级，相对偏差率必然爆表——
  改按绝对额与占收入比判定，不要因小基数误报
- **票据与保理**：应收票据+应收款项融资占比高 = 相对优质；附注「应收款项转移」
  的保理/证券化出表金额 = 坏账风险表外转移的隐藏披露

### 5. 存货异常（三维判定）
- **维度一·总量矛盾组合（X15，经营读法样板条目）**：存货增速远超收入增速，
  **且**存货周转率下降而毛利率反而上升。
  - **发生了什么**：货越堆越多、周转越来越慢，账面毛利却更高了——三个数字指向相反方向
  - **三解追问**（必须给**最可能的一解 + 依据**，禁止并列）：

    | 解释 | 区分证据 | 读法 |
    |---|---|---|
    | ① 产品结构升级 | `by_segment` 高毛利分部收入占比与毛利率同升 | 良性 🟢 |
    | ② 提价成功 | `rev_factors` 价正量负（价升量滞，存货被动积压） | 中性 🟡 |
    | ③ 渠道压货 | 应收同步走高 + 合同负债下降 + 库存商品占比升 | 恶性 🔴 |

  - 三解有其一 → 🟡 需要解释（写明是哪一解、依据是什么）；三解皆排除 → 🔴，
    回到旧轨：少结转成本虚增毛利（B2 roll-forward 闭合差 > 5% 佐证）
- **维度二·结构三分**（存货附注构成表，notes.inventory_mix）：

  | 构成项大增 | 信号 | 交叉验证 |
  |---|---|---|
  | 原材料 | 备产/锁价（乐观前瞻）| 次期收入是否兑现；mx_macro_data 原材料价格 |
  | 在产品 | 排产饱满 | 次期收入 |
  | 库存商品 | **滞销（最危险）** | 跌价准备率是否同步上升 |

- **维度三·roll-forward 数值化**（articulation.md B2）：期初 + 本期增加 − 营业成本 ≈ 期末，
  闭合差 > 5% 且毛利率同时上升 → 少结转成本嫌疑
- **滞销判定双条件**：库存商品↑ + 跌价准备率没跟上，两条同时成立才触发 🔴
- 行业降级：基酒贮存（白酒）、生产周期长（船舶/重型装备）的存货高企属工艺属性，
  看结构（在产品/自制半成品占比）而非总量

### 6. 其他应收款高企
- **判定**：其他应收款 ÷ 总资产 > 5%
- **发生了什么**：钱以「其他应收」名义流出主业——这是资金被占用的经典科目
- **最可能解释 + 区分**：最可能是大股东/关联方占用。区分证据：附注对象明细（关联方 = 🔴；
  押金/备用金/出口退税 = 经营属性 🟡）；配合 D3（母公司其他应收款 vs 合并）看内部资金池
- **下期验证**：其他应收款余额与对象明细变化、是否有清偿公告
- **出处**：其他应收款附注的对象明细

### 7. 商誉堰塞湖
- **判定**：商誉 ÷ 归母净资产 > 30%
- **发生了什么**：并购溢价悬顶，标的盈利撑不住账面估值
- **最可能解释 + 区分**：最可能是减值在路上。区分证据：减值测试假设（增长率/折现率）
  是否激进、标的业绩承诺完成率（承诺期刚过 = 减值高发窗口）
- **下期验证**：业绩承诺完成情况、减值测试假设变更、商誉减值公告
- **出处**：商誉附注的减值测试假设（增长率/折现率是否激进）

### 8. 在建工程长期挂账不转固
- **判定**：在建工程余额连续 2 年以上高位且工程进度接近 100% 却不转固
- **发生了什么**：工程「快完工」却迟迟不投产——要么烂尾、要么在躲折旧
- **最可能解释 + 区分**：最可能是拖延转固少提折旧。区分证据：进度表连续两期 ≈100% +
  同行业转固节奏对照 + 期后转固公告；转固后利润是否应声下滑（躲折旧的自我印证）
- **下期验证**：转固额（B3 roll-forward）、投产后产能利用率
- **出处**：在建工程附注的项目进度表

### 9. 控股股东高质押
- **判定**：质押比例 > 70%（tushare `pledge_stat` / 报告股东章节）
- **发生了什么**：大股东把股权押出去了——他自己缺钱
- **最可能解释 + 区分**：最可能是大股东资金链紧张。区分证据：质押率轨迹（持续上升 = 恶化）、
  距平仓线空间、是否伴随上市公司异常分红/关联采购放大（掏空前兆）
- **下期验证**：质押比例变化、补充质押/解除质押公告

### 10. 非经常性损益撑利润
- **判定**：扣非净利润 ÷ 归母净利润 < 70%
- **发生了什么**：主业不赚钱，利润靠「外快」撑
- **最可能解释 + 区分**：最可能是卖资产/政府补助/公允价值变动撑门面。区分证据：非经明细
  构成逐项点名；扣非增速 vs 归母增速——主业真实动能看扣非
- **下期验证**：扣非占比是否回到 70% 上方、非经构成是否再现大额资产处置

### 11. 债务覆盖不足
- **判定**：（货币资金 + 年经营现金流）÷（短期借款 + 一年内到期非流动负债）< 1
- **发生了什么**：短期要还的钱 > 手上现金 + 一年造血——流动性缺口
- **最可能解释 + 区分**：最可能是借新还旧依赖。区分证据：短债续贷/展期公告、授信额度变化；
  配合 `ocf_to_liab`（X6）看全口径偿债年限——短债口径紧 + 全口径年限长 = 结构性紧张
- **下期验证**：短债覆盖倍数、期后违约/展期公告

### 12. 公司治理硬伤
- 审计意见非标（保留意见/无法表示意见）、年报披露前更换会计师事务所
- 交易所问询函/监管函/立案调查（mx `mx_finance_search_notice` 核实）
- 财务总监/审计委员会成员频繁离职
- **发生了什么**：看门人报警或换人了——审计师/独董/监管对数字投了不信任票
- **最可能解释 + 区分**：最可能是数字有说不通的地方。区分证据：非标意见的形成基础逐条
  对照我们的勾稽异常（互相印证 = 最高强度）；年报披露前突击换所 = 买意见嫌疑；
  审计师为什么要跑，比「谁接的盘」更值得追问
- **下期验证**：问询函回复内容、下期审计意见走向
- **定位**：这是硬证据层——本条命中不需要三问降级，直接进报告核心结论

## 二、黄色信号（需要解释）

> 黄色条目的「追问方向」按三问前两问写：发生了什么 → 区分证据；验证项有共识的直接进 watchlist。

| 信号 | 判定 | 追问方向（发生了什么 → 区分证据） |
|---|---|---|
| 毛利率显著高于同行 | 高出同行均值 10pct+ | 毛利高到反常 → 有无产品/模式差异的硬解释（分产品毛利、定价权证据） |
| 研发资本化激进 | 资本化率 > 30% | 费用被挪进资产 → 同行费用化为主时为何要资本化；项目是否到可资本化节点 |
| 预付账款大增 | 增速远超收入 | 钱先付出去了 → 预付给谁、是否关联方；对应采购是否真实到货（期后入库） |
| 客户/供应商集中 | 前五大占比 > 50% | 命脉系于少数交易对手 → 集中度变化方向；大客户自身经营状况 |
| 关联交易占比高 | 关联销售/采购 > 20% | 买卖在自己人之间做 → 定价公允性（与非关联交易价差）、是否再生化 |
| 利息资本化 | 金额较大 | 利息没进费用 → 资本化依据（在建项目对应）、资本化率 |
| 高利润低分红 + 高质押 | 组合出现 | 赚着钱不分、大股东还押股 → 钱去哪了：货币资金受限/被占用对照 #1 |
| 分红同时大额融资 | 同年度出现 | 一手分钱一手要钱 → 是否大股东变相套现；融资必要性 |
| 费用率骤降 | 销售/管理费用率异常下降 | 费用突然「省」出来了 → 是否费用挂账或压缩必要投入（研发/质保） |
| 员工人数与业务背离 | 收入增、人数降且无解释 | 生意做大反而减人 → 真实性/外包化（人效三维勾稽，见第六节） |
| 合同负债/预收大幅收缩 | 同比下降 > 15% | 渠道打款意愿下降 → 先于收入的需求走弱先行指标；对照收入确认节奏 |
| 存货跌价准备大额转回 | 转回额 ÷ 存货余额 > 2%，或转回 > 当期计提 | 跌价准备又「回来」了 → A 股经典利润调节通道；计提与转回必须分列（notes.inventory_provision.cur_reversed） |

## 三、亮点信号（🟢，同样要有证据）

- ROE 连续 3 年 > 15% 且杠杆不升（杜邦分解验证由盈利/周转驱动而非加杠杆）
- 净现比 > 1（利润现金含量高）
- 毛利率/净利率趋势性上升，且能与产品结构升级对应
- 有息负债率持续下降、利息支出下降
- 合同负债（预收）大幅增长 = 订单能见度
- 研发费用率高且**费用化**（保守会计政策，利润质量高）
- 存货/应收周转天数改善
- 分红率提升或启动回购
- 股东户数下降 + 机构持仓上升（筹码集中）
- 经营现金流 > 资本开支（自由现金流转正/扩大）

## 四、使用纪律

1. 每条判定先找证据再找解释，最后定级（四态标准见第〇节：命中/观察/反向未触发/未触发）
2. 红色信号 ≥2 条时，在报告核心结论中显式提示「财务真实性风险聚集」
   （**只统计 `type=signal` 的红色条目**；MD&A 断言不实属 `type=assertion`，
   是「归因不实」而非「财务真实性」，不混计——见 extraction-schema.md signals 说明）
3. 周期股在底部的存货上升、扩张期的净现比偏低，属行业属性，降级处理
4. 信号库随实践迭代：发现新雷型时补录本文件

**anti-rationalization 标准反驳表（不接受空话，T10）**

分析中最常见的自我放纵是「用一句话把异常糊弄过去」。以下成对列出偷懒说法与标准回应——
回应不了就不许下「无异常」结论，只能定「无法解释」或「无法验证」：

| 偷懒说法 | 标准回应 |
|---|---|
| 「勾稽差 0.01 亿，四舍五入而已」 | 给出四舍五入前的原始数值与出处；给不出就按偏差立案，不许口头豁免 |
| 「这是正常波动」 | 列出近 5 期该科目数值：仍在历史区间内才准用「正常波动」；创出极值或超 ±2σ 必须解释驱动因素 |
| 「口径不同，不可比」 | 说清两个口径各自的定义、差异金额、影响方向；可量化必须量化后重算，量化不了定「无法验证」并写明缺口 |
| 「行业都这样」 | 给 2~3 家同业同口径数据；给不出 = 把行业惯例当挡箭牌，按无解释处理 |
| 「审计都过了，没问题」 | 康得新 2017 也是标准无保留意见。审计意见是证据之一，优先级不高于勾稽闭环与外部硬信息 |
| 「公司说是战略性投入/战略性亏损」 | 投入要有落点：资本开支/研发/在建工程哪一项对应？钱没去宣称方向 = 解释不成立 |
| 「一次性因素，明年就恢复」 | 一次性须同时满足：① 非经表有对应科目 ② 金额可指认 ③ 下期无持续影响证据；三条不齐按持续性恶化处理 |

## 五、审计视角交叉命中（P1-14）

**核心规则：关键审计事项（KAM）× redflag/勾稽异常 交叉命中 = 高危，直接 🔴。**
审计师最费力核实的科目，同时命中我们的阈值异常或勾稽偏差，等于两个独立视角指向同一处——
这是强度最高的信号组合。

操作步骤：
1. 从年报「关键审计事项」逐条提取 → 映射到财务科目（data.json `notes.audit.kam[].mapped_accounts`）
2. 对每个映射科目，检查是否同时命中：① redflags 信号 ② recon 勾稽异常
3. 交叉命中 → 🔴 且进报告核心结论；仅审计关注但无其他异常 → 🟡 观察

辅助指标：
- **审计收费 3 年趋势**（年报附注）：收费异常上涨可能对应审计范围扩大/风险上升；
  显著低于同业则审计独立性存疑
- **会计师更换轨迹**：报告期或临近期间更换 → 追查前任是否出具非标意见、
  是否在年报披露前突击更换（重风险信号）
- **其他信息源优先级不低于任何等式**（审计意见、独董异议、问询函、期后违约）

## 六、人效三维勾稽（P1-15）

把「员工人数与业务背离」这条定性黄色信号**操作化**——三条线同向才有说服力：

| 线 | 数据来源 | 
|---|---|
| 收入增速 | income.revenue |
| 员工人数增速 | notes.employees.headcount（年报「员工情况」表） |
| 支付职工现金增速 | cashflow.wage_cash |

背离判定表：

| 收入 | 人数 | 职工现金 | 判定 |
|---|---|---|---|
| ↑ | ↑ | ↑ | 正常扩张 🟢 |
| ↑ | ↓ | ↓ | 靠减员提效（可能触及天花板）或**收入真实性存疑**——虚增收入不会带来人和现金 |
| ↑↑ | ↑ | ↑↑↑ | 人力成本增速远超收入 = 人效恶化 🟡 |
| ↓ | ↑ | ↑ | 裁员滞后于收入下滑，利润将承压 🟡 |
| ↓ | ↓ | ↓↓ | 收缩中，关注是否伤及核心团队 |

配套指标：**人均创收 = 收入 ÷ 员工人数**、**人均薪酬 = 支付职工现金 ÷ 员工人数**，看趋势与同业对比。

**验收锚点**：茅台这类人效稳定的公司不得误报；虚增收入型样本（人数/现金不随收入走）必须命中。
