# 报告类型差异（report-types）

> Phase 0 识别报告类型后，按本文件裁剪模块。总原则：**报告含金量决定分析深度**——
> 年报最全，季报最轻；招股书结构不同，另起炉灶。

## 一、年报（全模块）

- 覆盖 Phase 0~8 全部模块
- 必看增量项：
  - **审计意见**（标准无保留？关键审计事项是什么）
  - **分红方案**（分红率、股息率、与上年对比）
  - 分产品量价表、成本构成表、在建工程明细——因素分析与产能分析的主数据源
  - 研发投入明细（费用化/资本化拆分）
- 措辞对比：与上年年报同章节对比

## 二、半年报

- 同比为主（vs 上年同期），环比参考（vs 当年一季度）
- 注明「未经审计」，审计意见模块裁剪
- 重点偏移：
  - 上半年经营回顾中对**下半年展望**的表述（接单、排产、价格指引）
  - 现金流科目波动大于年报属正常（结算周期），净现比异常需放宽口径
- 无分红方案或仅有中期分红预案
- 措辞对比：与上年半年报对比

## 三、季报（轻量版）

只跑三个精简模块：

1. **P2 精简**：核心三表科目 + 四维比率中的关键 6 项（ROE 年化、毛利率、净利率、
   资产负债率、收入/净利增速）
2. **P4 精简**：净利润桥（季报无成本构成明细，拆到毛利/费用/减值/非经为止）
3. **P7 精简**：机构预期对比 + 增收不增利判定

- 裁剪：排雷扫描只过「红色信号」快查（存贷双高、净现比、应收异常、质押）；
  文字分析、产能、股东模块裁剪（季报披露极简）
- 报告篇幅约为年报版的 1/3，文件名报告类型标「季报」

## 四、招股说明书（另起炉灶）

招股书没有「本期 vs 上期」的定期报告逻辑，结构改为：

### 专属模块
1. **发行方案**：发行价/募资额/发行市盈率 vs 可比公司估值（询价有效性）
2. **募投项目**：各项目投资金额/建设期/达产收益测算——判断产能押注方向与
   达产可信度（募投收益测算普遍偏乐观，注明假设激进程度）
3. **三年一期财务**：三年趋势分析替代同比分析（收入/利润 CAGR、毛利率轨迹、
   现金流轨迹）
4. **发行前后股权结构**：实控人持股比例变化、突击入股、对赌协议清理情况、
   员工持股平台
5. **风险提示专章**（权重上调）：招股书风险提示是最诚实的章节，逐条提炼为
   投资者真正需要盯的风险清单
6. **同业对比专章**：招股书自带可比公司对比（毛利率/研发费率/市占率），
   直接利用并与 tushare 数据交叉验证

### 裁剪模块
- 股东人数变化、机构预期对比（未上市无数据）→ 裁剪
- 热门赛道重合度保留（判断发行人是否在蹭 IPO 窗口热点）
- 排雷扫描全量保留（IPO 前粉饰动机最强，净现比/应收/毛利率异常从严）
- **上市前突击分红**专项检查：报告期分红 ÷ 募资额比例过高进风险清单

### 输出差异
- 文件名报告类型标「招股书」；综合评分改评「发行质量分」（商业模式 30% +
  财务质量 30% + 募投合理性 20% + 定价合理性 20%）

## 五、通用纪律

- 任何类型都先做 Phase 0/1（转换 + 双源核对）
- 裁剪的模块在报告目录中置灰标注「本报告类型不适用」，而不是悄悄消失——
  让读者知道哪些没分析
