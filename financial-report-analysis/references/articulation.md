# 勾稽验算手册（articulation）

> 本手册供 **Phase 2.5「勾稽验算」** 使用。每条等式给出：**公式 / 数据位置（年报章节附注名 +
> data.json 字段）/ 偏差阈值 / 异常含义 / 常见合理解释**。所有验算结果写入 data.json 的
> `recon` 块，输出三态：**✅闭合 / ⚠️可解释 / 🔴无法解释**（后者进 Phase 3 排雷清单；
> 报告徽章用短式，v0.0.19 起退役「可解释偏差/无法解释偏差」长标签）。
> 定位：redflags.md 判「结果层」（比率异常），本手册判「过程层」（差额从哪个科目来）。

## 使用总则

1. **先验算后判读**。每条先算出**偏差额**（lhs − rhs，亿元）与**偏差率**（|lhs−rhs| ÷ |rhs|），
   偏差率在阈值内直接判 ✅ 结案，不写分析文字；**超阈值才立案**，进入第 2 步找解释。
   禁止「看着可疑就立案」——没有偏差额支撑的怀疑不进 recon。
2. **偏差 ≠ 造假**。每条都配了「合理解释」，立案后**先逐条排除**（口径差、行业属性、
   一次性事项、金融子公司扰动），排除成功 → ⚠️可解释（`explanation` 必须写清是哪一条口径差，
   并附附注出处）；排除失败 → 🔴无法解释，同时在 `signals` 里落一条对应条目。
3. **三态输出规则（calc.py 机械拦截，见「与 calc.py 的对接」）**：偏差 ≤ 阈值却判「无法解释/
   可解释」= 过度立案 → FAIL；偏差 > 阈值却判「闭合」= 掩盖异常 → FAIL；判「无法解释」但
   `signals` 无对应条目 → WARN，Phase 7.5 前必须补齐；非「闭合」条目 `explanation` 不得为空。
4. **闭合 ≠ 真实（必要非充分，康得新教训）**。所有等式用的都是**公司自己披露的数字**——
   造假者可以在自己的账套里把等式做平（康得新 2018 年 A1 现金勾稽算术闭合，因为公司把 122.10
   亿已被资金归集的存款计为可用现金）。因此：
   - 勾稽闭合只证明「内部自洽」，**不证明「科目真实」**；后者只能靠附注细节、审计证据、
     期后事项与外部信息验证
   - 凡「勾稽闭合但审计/附注/独董异议指向该科目存疑」的，仍须立案，`verdict` 记「闭合」但
     `explanation` 写明外部反证，并同步在 `signals` 落条目
   - 反面亦然：审计意见、独董异议、问询函、期后违约等信息源，优先级不低于任何等式

**符号约定**：`ΔX = X.cur − X.prev`（期末 − 期初）；`avg(X) = (X.cur + X.prev) ÷ 2`；金额亿元，比率小数（0.10 = 10%）。

## A 组：三表恒等式（A1~A8）

跨表硬勾稽，A股年报披露项足以支撑全部 8 条。任一条 🔴 = 「三表不能自洽」，优先级高于 redflags 单条比率信号。

### A1 现金余额勾稽
- **公式**：货币资金（资产负债表） − 受限资金（附注） ≈ 期末现金及现金等价物（现金流量表补充资料）
- **数据位置**：资产负债表「货币资金」行 + 货币资金附注「使用受限/冻结/保证金」明细合计
  + 现金流量表补充资料末行「现金的期末余额」；
  data.json: `statements.balance.cash` / `statements.balance.restricted_cash` / `recon.A1_cash`
- **lhs / rhs**：`lhs = cash.cur − restricted_cash.cur`；`rhs =` 现金流量表补充资料「现金的期末余额」
  （schema 无独立叶子，直接填数值进 `recon.A1_cash.rhs`，`src` 写附注章节名+行号）
- **阈值**：偏差率 > **10%** 立案（calc.py `A1_cash` closure 0.10，分母为 `|rhs|`＝期末现金）。
  受限资金占比越高，分母口径影响越大（受限占 20% 时，同一偏差额算出的偏差率是「÷货币资金」口径的
  1.25 倍）——**门禁判定一律以 calc.py 的偏差率为准**
- **异常含义**：受限规模大（保证金/质押/司法冻结）或集团资金归集——**康得新式「账上有钱取不出」
  的直接验算入口**；与 redflags #1 存贷双高、#2 利息收入不匹配三条同向时，货币资金真实性直接列 🔴
- **合理解释**：票据保证金/信用证保证金随业务扩张、金融类子公司的法定存款准备金与存放同业、
  境外资金汇率折算差、期末在途资金（银行未达账项）

### A2 未分配利润滚动
- **公式**：期末未分配利润 = 期初 + 归母净利 − 提取盈余公积 − 现金分红（± 前期差错更正/其他权益变动）
- **数据位置**：资产负债表「未分配利润」「盈余公积」两期 + 利润表归母净利
  + 所有者权益变动表「利润分配」各行 / 利润分配附注；
  data.json: `statements.balance.retained_cur` / `surplus_reserve` / `dividend_paid`、
  `statements.income.np_at`、`recon.A2_retained`
- **lhs / rhs**：`lhs = retained_cur.cur`；
  `rhs = retained_cur.prev + np_at.cur − (surplus_reserve.cur − surplus_reserve.prev) − dividend_paid.cur`
- **阈值**：偏差率 > **2%** 立案（calc.py 已内置 A2 校验，`check_retained_roll` 用同一等式，
  不平会给 WARN；recon 填了则按 closure 0.02 强判三态）
- **异常含义**：等式不平本身就是信号——指向**前期差错更正、OCI 结转（其他综合收益转留存）、
  永续债/其他权益工具利息从留存中扣除、股份支付行权结转**；同时验证分红能力与利润是否匹配
  （高利润却常年不分红 + 大股东高质押 = redflags 黄色表「高利润低分红+高质押」组合，要警惕）
- **合理解释**：中期已分红（`dividend_paid` 需含中期，只填年度分红必然不平）、
  专项储备/安全生产费提取、同一控制下合并追溯调整期初、子公司向少数股东分红不影响本等式（别误加）

### A3 间接法现金流量调节表 ★全报告最大单项缺口，盈利质量第一解剖刀
- **公式**：净利润 + 折旧摊销 + 资产减值 ± 递延所得税 ± Δ经营性应收 − Δ存货 + Δ经营性应付 ± 其他
  = 经营活动现金流量净额
- **数据位置**：年报「现金流量表补充资料」（附注末段，A股**强制披露**）逐行照抄：净利润 /
  资产减值准备 / 固定资产折旧 / 无形资产摊销 / 长期待摊摊销 / 处置损益 / 公允价值变动 /
  财务费用 / 投资损益 / 递延所得税 / 存货的减少 / 经营性应收的减少 / 经营性应付的增加 / 其他；
  data.json: `derived.ocf_bridge`（**首项「净利润」填水平值 `statements.income.np_total.cur`
  （含少数股东，不是归母）**，其余填调节额，符号按「增加 OCF 为正」）→ Σ = `statements.cashflow.ocf.cur`；
  `recon.A3_indirect`
- **lhs / rhs**：`lhs = Σ derived.ocf_bridge[*].delta`；`rhs = statements.cashflow.ocf.cur`
- **阈值**：桥闭合容差由 calc.py 判定（**2%×OCF 与 0.5%×净利润 取大**，绝对下限 0.01 亿；
  recon 侧 `A3_indirect` closure 0.02）。**另算「营运资本现金吞噬额」**（正数 = 吞噬现金）：
  `wc_devour.amount = −(Δ应收 + Δ存货 − Δ应付 − Δ其他)`，**四项一律取 `ocf_bridge` 中的 delta 值**
  （桥内符号约定「增加 OCF 为正」，故整式取负后即吞噬额）——即
  `amount = −(Σ「Δ应收」「Δ存货」「Δ应付」「其他营运资本」四项 delta)`。
  **禁止用 `balance.ar` 等科目余额差直接代入**：补充资料行的「经营性应收」是宽口径
  （含财务公司发放贷款、拆出资金），与 `balance.ar` 差额可能相差数十亿。
  `wc_devour.share_of_np = amount ÷ np_at.cur`；**吞噬额 > 净利润 50% → 盈利质量警示**，
  为 redflags #3 净现比提供量化依据（写进 signals）
- **异常含义**：净现比只告诉你「利润和现金不匹配」，调节表告诉你**「差在 Δ应收还是 Δ存货、
  各吞了多少现金」**——这是把结果层升级为过程层的关键。典型读数：
  Δ应收吞噬为主 → 接 A4/B1 查收入质量；Δ存货吞噬为主 → 接 B2 查备货还是滞销；
  「其他」项金额畸大且方向反常 → 关联方往来或非经营性资金占用藏在这里
- **合理解释**：高速扩张期备货与铺底、季节性回款节奏（Q4 发货 Q1 回款）、
  金融子公司存贷款业务扰动（如茅台财务公司：吸收存款/发放贷款进经营性现金流，
  使 Δ应收/Δ应付口径与实业公司不可比）、票据背书/贴现的现金流分类差异

### A4 收入-收现闭环
- **公式**：销售商品提供劳务收到的现金 ≈ 营业收入 × (1 + 增值税率) + Δ合同负债 − Δ应收（含票据）
  − 本期核销 − Δ预收（并入合同负债时不重复计） + Δ其他往来
- **数据位置**：现金流量表「销售商品、提供劳务收到的现金」+ 利润表营业收入
  + 资产负债表合同负债/应收账款/应收票据及应收款项融资/预付款项两期；
  data.json: `statements.cashflow.sales_cash`、`statements.income.revenue`、
  `statements.balance.contract_liab` / `ar` / `ar_notes`、`recon.A4_rev_cash`
- **lhs / rhs**：`lhs = sales_cash.cur`；
  `rhs = revenue.cur × 1.13 + Δcontract_liab − Δ(ar + ar_notes) − notes.ar_writeoff.cur`
  （1.13 = 13% 增值税率的含税还原，白酒/制造业通用；税率不同按实际调整并在 `explanation` 注明。
  **必须含核销项，与 B1 口径一致**，否则两条等式会互相矛盾。「Δ预收/其他往来」多数公司已并入
  合同负债，单列时再加）
- **阈值**：偏差率 > **10%** 立案；**重点看方向连续性**——连续 2~3 年同向缺口才是结构性信号
  （单看收现比 `derived.ratios.cash_to_sales` 的 1.13 静态锚点会漏掉「年年 1.13 → 1.05 → 0.95」
  的结构性恶化，务必用 `hist` 三期并列看）
- **异常含义**：**系统性低于** rhs = 收入确认激进（白条收入、期末集中发货未回款、
  以应收/票据换收入），接 redflags #4；**系统性高于** rhs = 收入确认保守或预收模式
  （订单能见度强，🟢），但也要排除票据贴现回笼与保理出表（`notes.ar_factoring`）造成的「假收现」
- **合理解释**：增值税率变化/出口退税与免税收入占比、票据结算占比高（票据未贴现不计入收现）、
  金融子公司利息收入不进本行（走「收取利息、手续费及佣金的现金」）、
  并表范围变动（新并购子公司收入与期初应收不可比）

### A5 折旧摊销勾稽
- **公式**：现金流量表补充资料的折旧摊销 ≈ 固定资产附注「本期折旧额」+ 无形资产附注「本期摊销」
  + 长期待摊费用附注「本期摊销」
- **数据位置**：现金流量表补充资料「固定资产折旧/无形资产摊销/长期待摊费用摊销」三行 + 固定资产
  附注累计折旧 roll-forward 行 + 无形资产/长期待摊附注；data.json: `statements.cashflow.dep_amort`、
  `recon.A5_dep_amort`（rhs 三个分项 schema 无独立叶子，数值直接填，`src` 写附注名）
- **lhs / rhs**：`lhs = dep_amort.cur`；`rhs =` 固定资产本期折旧 + 无形资产本期摊销 + 长期待摊本期摊销
- **阈值**：偏差率 > **5%** 立案（calc.py `A5_dep_amort` closure 0.05）
- **异常含义**：差异指向**资本化口径变化、在建转固节奏异常**。注意：B3 显示进度高却不转固时，
  A5 两边会同幅度偏低而「假闭合」——此时补算 `dep_amort.cur ÷ avg(固定资产原值 + 使用权资产)`
  得隐含折旧率，与同业（制造业常见 5%~10%）对照，显著偏低即与 redflags #8 联动立案；
  **折旧年限延长（会计估计变更）的利润影响要量化**：在「会计估计变更」附注找变更前后年限，
  估算 Δ折旧 = 相关资产原值 × (1/旧年限 − 1/新年限)，写入 signals 作为利润美化证据
- **合理解释**：使用权资产折旧单列（租赁准则下不在「固定资产折旧」行，
  schema 的 `lt_debt` 含租赁负债而 `dep_amort` 未必含使用权折旧，差额常见于此）、
  本期处置资产的折旧口径差（处置月份停止计提）、投资性房地产采用公允价值模式不计提折旧

### A6 Capex 勾稽
- **公式**：购建固定资产等支付的现金 ≈ (固定资产 + 在建工程)净增加 + Δ应付工程设备款 + 折旧
- **数据位置**：现金流量表投资段「购建固定资产、无形资产和其他长期资产支付的现金」+
  资产负债表固定资产/在建工程两期 + 附注「应付工程设备款/应付账款-工程物资」；data.json:
  `statements.cashflow.capex`、`statements.balance.cip` / `payable_construction`、`recon.A6_capex`
- **lhs / rhs**：`lhs = capex.cur`；
  `rhs = Δ固定资产净值 + Δcip + Δpayable_construction + dep_amort.cur`
  （`balance.fixed_assets` 已入 schema，取数后直接参与 rhs 计算并把出处写进 `recon.A6_capex.src`）
- **阈值**：偏差率 > **10%** 立案（calc.py `A6_capex` closure 0.10）
- **异常含义**：`payable_construction` 持续膨胀 = **变相占用上游资金搞建设**，
  扩张的真实资金压力被低估（表观 capex 低但已签未付的资本承诺大，
  对照附注「资本性支出承诺/未付工程保证金」）；lhs 远大于 rhs = 存在无形资产/长期待摊大额投入
  或预付工程设备款（钱出去了资产没形成，查是否流向关联方）；与 Phase 6 在建工程分析天然联动
- **合理解释**：本期处置/报废固定资产（原价减少使 Δ 偏低，需加回处置原价后再比）、
  capex 含无形资产与长期待摊投入而 rhs 只有固定资产/在建工程（口径不对称，最常见的偏差源）、
  购入即转固的设备（跳过 cip，但已计入 Δ固定资产，不影响本式）、
  政府补助冲减资产账面价值（净额法下 Δ资产被低估）、融资租赁/售后回租取得的资产不走 capex 行

### A7 隐含利率检验（level 型）
- **公式**：利息费用 ÷ 平均有息负债 = 隐含利率；并对照「财务费用附注利息支出」vs
  「现金流量表实际付息」，差额 = 应付未付利息
- **数据位置**：利润表财务费用附注「利息支出」+ 资产负债表有息负债（短借 + 一年内到期 +
  长借 + 应付债券，`lt_debt` 已含长借/债券/租赁负债）两期 + 现金流量表「分配股利、利润或
  偿付利息支付的现金」中的利息部分；data.json: `statements.income.interest_exp`、
  `statements.balance.st_debt` / `noncur_due_1y` / `lt_debt`、`statements.cashflow.interest_paid`、
  `recon.A7_implied_rate`
- **lhs / rhs**（**level 型**，calc.py 判 `lhs > rhs` 即异常）：
  `lhs = interest_exp.cur ÷ avg(st_debt + noncur_due_1y + lt_debt)`（小数）；
  `rhs = 0.08`（基准阈值，按公司融资结构填：央企/高评级 0.05，民企一般 0.08，
  含票据贴现或非标融资时 0.10；**rhs 是分析师填的基准，不是算出来的值，必须在 explanation 说明取值依据**）
  副算：`应付未付利息 = interest_exp.cur − interest_paid.cur`
- **阈值**：隐含利率 > **8%** 立案；**应付未付利息持续为正且扩大 = 资金链紧张先行信号**
  （单期为正可能是付息日错期，连续 2 年为正且余额上升才立案）
- **异常含义**：隐含利率畸高 → **表外负债（担保/明股实债）、集团资金占用（借出去的钱收不回利息、
  自己的借款利息照付）、民间借贷或非标融资嫌疑**；隐含利率远低于市场（<2%）同样异常
  → 有息负债未足额入账或利息被资本化（对照利息资本化金额，redflags 黄色表）
- **合理解释**：年内新增借款拉高期末余额、平均口径（用 avg 而非期末）造成的分母偏大、
  票据贴现息计入财务费用而非利息支出、利息资本化使费用化利息小于真实融资成本、
  财务公司同业存放利息支出混入（金融子公司，需剔除后再算）

### A8 投资收益合理性（level 型）
- **公式**：投资收益 ÷ (交易性金融资产 + 长期股权投资 + 其他非流动金融资产) = 隐含收益率
- **数据位置**：利润表「投资收益」+ 资产负债表对应三项金融资产科目（schema 已合并为一个字段）；
  data.json: `statements.income.invest_income`、`statements.balance.fin_assets`、`recon.A8_invest_income`
- **lhs / rhs**（**level 型**）：`lhs = invest_income.cur ÷ avg(fin_assets)`（小数，
  `fin_assets.prev` 缺失时用期末值代替并在 explanation 注明）；
  `rhs = 0.10`（国债/理财正常区间上沿；金融资产以权益法长期股权投资为主时填 0.08~0.10，
  以理财/结构性存款为主时填 0.04~0.05——**rhs 取值必须与 fin_assets 的实际构成匹配**，
  构成从附注「交易性金融资产/长期股权投资明细」读）
- **阈值**：隐含收益率远超国债/理财正常区间（**> 8%~10%**）立案
- **异常含义**：**关联方输血或金融资产公允价值操纵**（被投资方是关联方且分红异常、
  年末突击处置交易性金融资产确认收益）；redflags #10 只看扣非占比，
  **抓不住「非经常损益藏在投资收益里」的情形**——权益法下联营企业利润按持股比例进投资收益，
  属经常性损益但完全依赖被投资方，需追问被投资方盈利可持续性
- **合理解释**：处置子公司/联营企业股权的一次性收益（查附注「处置子公司」与并表范围变动）、
  权益法核算被投资方本身高盈利（如持有优质金融/消费股权）、
  公允价值变动损益与投资收益口径混用（部分公司两行合并披露）、
  分母漏项（其他权益工具投资、债权投资不在 `fin_assets` 内时 lhs 被高估）

## B 组：科目 Roll-forward（B1~B4）

单科目「期初 + 增加 − 减少 = 期末」滚动验算，抓**科目内部的暗箱操作**（核销、少结转、不转固、
不减值）。附注披露不全时按各条的降级路径处理，不要硬凑。

### B1 应收 roll-forward
- **公式**：期初应收（含票据） + 本期赊销 − 本期应收回款 − 核销 ± 其他 ≈ 期末应收（含票据）
  现销/赊销分不开时用净额法（赊销 = 含税收入 − 现销，应收回款 = 销售收现 − 现销 − Δ合同负债，
  相减后**现销自动抵消**）：`期初应收 + 含税收入 + Δ合同负债 − 销售收现 − 核销 ≈ 期末应收`
  （**Δ合同负债必须保留**：预收增加是「收了钱没确认收入」，漏掉会让预收模式公司系统性不平）
- **数据位置**：资产负债表应收账款/应收票据及应收款项融资/合同负债两期 + 应收附注
  「坏账准备 roll-forward」（期初计提余额 + 本期计提 − 本期转回 − **本期核销** ± 汇率）
  + 现金流量表销售收现；data.json: `statements.balance.ar` / `ar_notes` / `contract_liab`、
  `statements.income.revenue`、`statements.cashflow.sales_cash`、
  `notes.ar_writeoff`、`notes.ar_provision`、`notes.ar_factoring`、`recon.B1_ar_roll`
- **lhs / rhs**：
  `lhs = (ar.prev + ar_notes.prev) + revenue.cur × 1.13 + Δcontract_liab − sales_cash.cur − ar_writeoff.cur`；
  `rhs = ar.cur + ar_notes.cur`（1.13 = 含税还原，与 A4 同一口径；税率不同按实际调）
- **阈值**：偏差率 > **5%** 立案（calc.py `B1_ar_roll` closure 0.05，分母 `|rhs|`）
  **小基数陷阱**：应收极小的公司（如 `ar.cur + ar_notes.cur` < 收入的 1%）相对偏差率无意义，
  必然超阈值——此时判 ⚠️`可解释`，`explanation` 写「应收基数仅占收入 x%，改按绝对额判定：
  偏差 y 亿」，并在文字里改看绝对额与 `notes.ar_aging` 结构，**不要因小基数判 🔴**
- **异常含义**：**核销 > 当年计提 = 长期计提不足铁证**（接坏账计提不足线索）——
  对照 `notes.ar_aging` 各账龄 `prov_rate_cur` vs `prov_rate_prev`，计提比例下调 + 大额核销
  同时出现，直接列 🔴；lhs 远小于 rhs（应收凭空多出）= 存在未披露的应收增加渠道
  （保理回购、票据转入、并购并表），`ar_factoring` 有值时先看是否「假出表真融资」
- **合理解释**：坏账核销走附注而未进主表口径、应收保理/证券化出表（`ar_factoring`）、
  并表范围变动带入应收、汇率折算（外币应收）、票据背书转让终止确认、
  票据贴现息使收现小于含税应收额（贴现息走财务费用）、
  其他应收款/预付渠道的收入相关往来未纳入本式（`statements.balance.other_ar` / `prepayment`）

### B2 存货 roll-forward
- **公式**：期初存货 + 本期生产入库（采购 + 人工 + 制造费用） − 结转营业成本 ≈ 期末存货
  **简化校验**：期初 + 本期增加 − 营业成本 ≈ 期末
- **数据位置**：资产负债表存货两期 + 存货附注「账面余额构成」（原材料/在产品/库存商品/
  自制半成品/开发成本）+ 附注「存货本期增加额」（部分公司披露生产成本表：直接材料/直接人工/制造费用）
  + 利润表营业成本；data.json: `statements.balance.inventory`、`statements.income.cost`、
  `notes.inventory_mix`、`notes.inventory_provision`、`recon.B2_inv_roll`
- **lhs / rhs**：`lhs = inventory.prev + 本期增加额（附注） − cost.cur`；`rhs = inventory.cur`
  **本期增加额无披露时不硬凑**：降级为方向性联合校验（见阈值），recon 留空由 calc.py SKIP
- **阈值**：闭合差 = `lhs − rhs`，|闭合差| ÷ `rhs` > **5%**（calc.py `B2_inv_roll` closure 0.05）
  **且 `derived.ratios.gross_margin.cur` 同比上升 → 少结转成本嫌疑**
  （redflags #5「存货增速远超收入 + 周转率下降而毛利率上升」矛盾组合的数值版，两者同时成立直接 🔴）
- **异常含义**：**闭合差为负**（`rhs > lhs`，账面期末存货比推算值高）= 成本少结转、存货虚增，
  配合毛利率上升互证；**闭合差为正**（`lhs > rhs`）= 多结转成本（利润平滑/藏利润，配合
  `inventory_provision.cur_reversed` 大额转回看是否「洗大澡后反冲」）；`inventory_mix` 里
  **库存商品占比上升而原材料下降** = 由备货扩张转为卖不动，比总额变化更早预警
- **合理解释**：附注「本期增加」口径不含委托加工物资/发出商品、存货跌价准备核销、
  非同一控制合并并入存货、消耗性生物资产与存货分列（农业/白酒制曲口径）、
  在建工程领用自产产品（视同销售，存货减少但不进营业成本）

### B3 在建工程 roll-forward
- **公式**：期初 + 本期投入 − 转固 − 减值 ≈ 期末
- **数据位置**：资产负债表在建工程两期 + 在建工程附注**项目进度表**（项目名/预算/累计投入/
  工程进度%/本年转入固定资产额/减值准备）+ 现金流量表 capex；data.json:
  `statements.balance.cip`、`notes.cip_projects`（`invested_cur` / `progress` / `transferred`）、
  `statements.cashflow.capex`、`recon.B3_cip_roll`
- **lhs / rhs**：`lhs = cip.prev + Σ notes.cip_projects[*].invested_cur
  − Σ notes.cip_projects[*].transferred − 本期减值`；`rhs = cip.cur`
  **交叉验证**：Σ`invested_cur` 应 ≤ `capex.cur`（capex 还含无形资产/长期待摊/直接购入固定资产），
  Σ`invested_cur` 明显大于 capex = 投入未实际付现，查应付工程款或资金流向
- **阈值**：偏差率 > **5%** 立案（calc.py `B3_cip_roll` closure 0.05）
- **异常含义**：**长期挂账不转固**（redflags #8）——`progress` ≥ 90% 却 `transferred` = 0
  的项目逐个列出并算「若转固应补提折旧」（项目金额 ÷ 预计使用年限），量化利润美化幅度；
  同一项目连续 2 年 `progress` 不动 = 项目烂尾却未计提减值（🔴）；
  在建工程余额增速远超 capex = 存在非现金投入渠道（关联方代建、以资抵债）
- **合理解释**：项目分期建设分批转固（进度按整体口径披露，转固按单体）、
  试生产收入冲减在建工程成本（新准则下冲减而非计收入）、
  利息资本化计入在建工程（金额大时 lhs 需加上资本化利息）、工程物资单列科目

### B4 商誉 roll-forward
- **公式**：期初 + 本期新增（非同一控制下企业合并） − 减值 = 期末（**应严格相等**）
- **数据位置**：资产负债表商誉两期 + 商誉附注（分资产组/子公司明细：期初余额、本期增加、
  本期减值、期末余额）+ 减值测试假设（增长率/折现率/预测期）；
  data.json: `statements.balance.goodwill`、`notes.goodwill_test`
  （`growth_assumption` / `discount_rate`）、`recon.B4_goodwill_roll`
- **lhs / rhs**：`lhs = goodwill.prev + 本期新增 − 本期减值`；`rhs = goodwill.cur`
- **阈值**：偏差率 > **1%** 立案（calc.py `B4_goodwill_roll` closure 0.01，
  商誉是纯账务科目，无口径差空间，1% 已是宽松容差）
- **异常含义**：不平 = 提取错误或存在未披露的商誉处置/分摊调整（如商誉随资产组处置转出、
  外币报表折算差计入商誉）；**减值计提是否充分要对照 `notes.goodwill_test`**：
  折现率显著低于同业（<10%）、永续增长率高于 GDP（>3%）、被收购标的实际业绩低于承诺
  却仍「测试通过不减值」→ 结合 redflags #7 商誉 ÷ 归母净资产 > 30% 直接列 🔴
- **合理解释**：分步收购的商誉重估、处置子公司时商誉一并转出、汇率折算差、
  本年新增并购的合并对价分摊尚未完成（披露为暂定数）

## C 组：周期联动（C1~C2）

不产生 `recon` 条目（calc.py 的 `RECON_RULES` 不含 C 组），结果写入 `derived.ratios` 与 `signals`，
判读规则在 frameworks.md 营运能力节，本组只给**勾稽口径**；第三条是「口径与算法」而非「lhs / rhs」。

### C1 CCC 现金转换周期
- **公式**：`CCC = DSO + DIO − DPO`，三期趋势 + 行业对照
- **数据位置**：资产负债表应收账款/应收票据/存货/应付账款/应付票据两期 + 利润表收入、成本；
  data.json: `derived.ratios.dso` / `dio` / `dpo` / `ccc`（带 `cur` / `prev`，三期看 `hist`），
  原始科目取 `statements.balance.ar` / `inventory`、`statements.income.revenue` / `cost`
- **口径与算法**（平均余额法，与 calc.py `build_ratio_calcs` 一致）：
  - `DSO = avg(ar) × 365 ÷ revenue.cur`（含 `ar_notes` 更保守；calc.py 现只用 `ar`，
    改合并口径须在 `derived.ratios.dso` 的 note 里说明差异）
  - `DIO = avg(inventory) × 365 ÷ cost.cur`（分母用营业成本，不是收入）
  - `DPO = avg(payable) × 365 ÷ cost.cur`（`payable` = 应付账款+应付票据，schema 字段
    `balance.payable`；calc.py 已用它自动复算 dpo/ccc，无需手工回填）
- **阈值 / 判读规则**：**CCC 持续拉长 + 收入高增 = 以营运资本换增长**（配合 A3 的
  `wc_devour.share_of_np` > 50% 互证，🟡，扣成长质量维度分）；**CCC 收窄 = 造血改善**（🟢）；
  **CCC 拉长但收入停滞 = 单纯运营恶化**（🔴）
- **异常含义**：CCC 拉长说明每一元收入占用更多营运资本，与 A3 的 Δ应收/Δ存货吞噬现金互证时
  「增长靠垫资」成立；单看 DSO 或 DIO 任一项无法区分行业性账期延长与本公司信用政策放松
- **合理解释**：业务模式切换（直销转经销、增加票据结算）、并购并表带入不同账期的应收、
  行业性账期延长（需同业对照）、季节性（半年报 CCC 与年报不可直接比）

### C2 DPO 双面性判读
- **公式**：应付账期拉长有**两种相反含义**，必须配合第二坐标（短债覆盖）联合判定，**单一指标不判**：

| DPO 变化 | 货币资金/短债覆盖 | 判定 |
|---|---|---|
| 拉长 | 货币资金充裕、`short_debt_cover` ≥ 2 | 对上游议价力增强 🟢 |
| 拉长 | `short_debt_cover` < 1.5 | 拖欠供应商 🔴 |

- **数据位置**：资产负债表应付账款/应付票据、货币资金、短期借款、一年内到期非流动负债两期
  + 现金流量表经营净额；data.json: `derived.ratios.dpo`、`derived.ratios.short_debt_cover`、
  `statements.balance.cash` / `st_debt` / `noncur_due_1y`、`statements.cashflow.ocf`；判定结果落 `signals`
- **口径与算法**：`short_debt_cover = (cash.cur + ocf.cur) ÷ (st_debt.cur + noncur_due_1y.cur)`
  （calc.py 内置复算并比对，不符 → FAIL）；DPO 口径同 C1
- **阈值 / 判读规则**：覆盖 ≥ 2 且 DPO 拉长 → 🟢；覆盖 < 1.5 且 DPO 拉长 → 🔴；
  **中间地带（1.5~2）判 🟡**：追问应付账款账龄结构（附注「1年以上应付」占比上升 = 拖欠信号）
  与供应商集中度（前五大供应商占比 + 是否有关联方）
- **异常含义**：拖欠型 DPO 拉长是**资金链紧张的上游版**，与 A7「应付未付利息持续为正」同源
  （都是「该付的钱压着不付」），同时出现时债务压力判定升级；议价力型则是无息负债扩张，属商业模式优势
- **合理解释**：议价力增强通常伴随采购规模扩大与合同负债同步增长（两头占款）；拖欠通常伴随
  其他应付款上升、诉讼/仲裁披露、供应商停供的期后事项（`notes.subsequent_events`）

## 与 calc.py 的对接

- **每条 recon 条目五个键**：`lhs`（等式左边计算值）/ `rhs`（右边计算值或基准阈值）/
  `verdict` ∈ {`闭合`, `可解释`, `无法解释`} / `explanation`（非「闭合」必填，写口径差或风险定性）/
  `src`（出处，附注章节名+行号，禁止空串）
- **阈值与类型已内置**（`scripts/calc.py` 的 `RECON_RULES`，勿在本手册重复维护数字）：

| recon 键 | 类型 | 阈值 |
|---|---|---|
| `A1_cash` / `A4_rev_cash` / `A6_capex` | closure | 10% |
| `A5_dep_amort` / `B1_ar_roll` / `B2_inv_roll` / `B3_cip_roll` | closure | 5% |
| `A2_retained` / `A3_indirect`（另有 `bridge.ocf` 容差 2%×OCF 与 0.5%×净利取大） | closure | 2% |
| `B4_goodwill_roll` | closure | 1% |
| `A7_implied_rate`（rhs 基准 0.05/0.08/0.10）/ `A8_invest_income`（rhs 基准 0.04~0.10） | **level** | lhs > rhs |

- **closure 型**：`dev = |lhs − rhs| ÷ |rhs|`。`dev ≤ 阈值` 而 `verdict ≠ 闭合` → **FAIL（过度立案）**；
  `dev > 阈值` 而 `verdict = 闭合` → **FAIL（掩盖异常）**；`dev > 阈值` 且 `verdict = 无法解释`
  → WARN，**必须确认 `signals` 中有对应条目**；`dev > 阈值` 且 `verdict = 可解释` → OK
- **level 型（A7/A8）**：`lhs` = 计算值（隐含利率/隐含收益率，小数），`rhs` = 基准阈值。
  `lhs > rhs` 却判「闭合」→ FAIL；`lhs ≤ rhs` 却判「可解释/无法解释」→ FAIL。
  **rhs 由分析师按公司融资结构与金融资产构成填，取值依据写进 `explanation`**
- **缺数处理**：`lhs`/`rhs` 任一为 `null` 时，填了 `verdict` 会 FAIL（无算据的判定不成立），不填则 SKIP
  ——**附注确实未披露就整条留空，禁止用 0 或估算值占位后判「闭合」**
- **C1/C2 不进 recon**：写入 `derived.ratios`（calc.py 复算 `dso`/`ccc`/`short_debt_cover`
  并比对，不符 → FAIL）与 `signals`

## D 组：母公司单体报表勾稽（P2-24）

A 股年报强制披露「母公司资产负债表/利润表/现金流量表」。**合并报表好看而母公司报表露馅**
是资金占用型造假的典型特征（康得新式），成本极低但常被忽略。

| 编号 | 等式 / 检验 | 阈值与判读 |
|---|---|---|
| D1 | **母公司货币资金 vs 合并货币资金** | 母公司占比长期极低（如 <10%）而集团现金充裕 → 资金沉淀在子公司，须查子公司资金是否被归集/占用 |
| D2 | **母公司未分配利润 vs 拟分红额** | 母公司未分配利润不足以覆盖分红、或分红依赖子公司上缴 → 分红能力受子公司制约；配合「子公司分红汇回」现金流看 |
| D3 | **母公司其他应收款 vs 合并其他应收款** | 母公司其他应收款占合并大头 → 内部往来资金池，查是否流向非全资子公司/关联方 |
| D4 | **母公司投资收益 vs 子公司利润** | 母公司利润几乎全部来自投资收益 → 自身无经营，是纯控股平台；集团风险集中在子公司 |
| D5 | **母公司经营性现金流** | 常年为负而合并为正 → 母公司靠子公司分红/借款维持，资金调度痕迹 |

**用法**：D1/D2/D3 任一异常 → 🟡 观察；D1+D3 同时异常 → 🔴（资金归集/占用嫌疑），
