# 分析框架（frameworks）

> Phase 2 的公式与阈值权威定义。所有比率注明 tushare 对应字段，便于机算。

## 〇、口径总则（所有比率与模型的前置规矩，calc.py 复算卡口同源）

1. **存量比存量、流量比流量**：资产/负债类存量（货币资金/总资产等）不做年化；
   收入/成本/利润等流量在跨期次比较或代入模型（Altman/Ohlson 等）前必须年化——
   **年化因子：一季报 ×4、半年报 ×2、三季报 ×4/3、年报 ×1**
2. **平均余额窗口必须与分母期间匹配**：期初一律取「该期所在年度的上一年 12-31」
   （半年报取 hist_ye，不取上年 6-30——H1 收入只对应 1-6 月的资金占用）；
   详见第一节 CCC 平均余额口径
3. **同比必须同口径**：半年报的上期=上年同期（H1 对 H1）；找不到同口径上期
   （口径断裂、期次不齐）→ 该同比指标置「无法计算」并标注 `period_mismatch`，
   **拒算强于错算**，禁止跨口径硬比
4. **强季节性公司的年化值标「粗年化」并降权**：白酒 Q1 占全年 40%+ 这类公司，
   中期年化会系统性失真——年化值只作量级参照，模型结论降一档措辞

## 一、四维比率

### 盈利能力
| 指标 | 公式 | tushare 字段（fina_indicator） | 参考线 |
|---|---|---|---|
| ROE（摊薄/加权） | 归母净利润 ÷ 归母净资产 | `roe` / `roe_waa` | >15% 优，<8% 弱 |
| 毛利率 | (收入−成本)÷收入 | `grossprofit_margin` | 看趋势与同业差 |
| 净利率 | 净利润 ÷ 收入 | `netprofit_margin` | 看趋势 |
| ROIC | NOPAT ÷ 平均投入资本 | `roic`（v1.4 起 calc 复算，口径见下） | >8% 及格 |
| 期间费用率 | 三费+研发 ÷ 收入 | 销售/管理/财务费用 | 逐年对比 |
| 非主营业务收入占比 | (营业外收入+其他业务收入+投资收益+公允价值变动) ÷ 营业收入（X33） | 手算（income 四字段） | 升 = 需解释：主业造血 vs 靠投资与公允撑利润，须拆解构成再定性 |

**ROIC 口径（v1.4 落库 derived.ratios.roic，calc.py 复算卡口）**：NOPAT = EBIT×(1−有效税率)，
EBT≤0 时有效税率按 0（亏损期无税盾可抵）；投入资本 = 有息负债（st_debt+noncur_due_1y+lt_debt，
null 按 0）+ 归母权益，期初取 prev 期末；期间口径不年化（与本体系 ROE 同约定）。**与杜邦的
关系**：ROIC 是去杠杆口径，杜邦拆的 ROE 含杠杆效应——两口径并列读，ROE−ROIC 差值大 = 回报
靠杠杆撑（化险期地产等高杠杆模式尤其要看这个差）。单期指标：上期需 T-2 期投入资本，不可得，
不做两期对比。

### 营运能力
| 指标 | 公式 | tushare 字段 |
|---|---|---|
| 应收账款周转天数 | 365 ÷ 应收周转率 | `ar_turn` / `arturn_days` |
| 存货周转天数 | 365 ÷ 存货周转率 | `inv_turn` / `invturn_days` |
| 总资产周转率 | 收入 ÷ 平均总资产 | `assets_turn` |

**CCC 现金转换周期（把孤立天数串成系统）**

```
CCC = DSO + DIO − DPO
DSO = 平均应收 × 365 ÷ 营业收入
DIO = 平均存货 × 365 ÷ 营业成本
DPO = 平均应付 × 365 ÷ 营业成本   （应付 = 应付账款+应付票据，schema: balance.payable）
```

- **平均余额口径（期初取上年末，定案）**：「平均」的窗口必须与分母的期间匹配——H1 收入只对应
  1-6 月的资金占用，所以**任何一期的期初一律取该期所在年度的上一年 12-31**，期末取该期期末
  （年报=12-31，半年报=6-30）。半年报绝不取上年 6-30 当期初（窗口错配，天数系统性偏低），
  期初数据落 balance 叶子的 `hist_ye`（各年 12-31 序列，末位=prev）；年报期初=hist 前一期，
  天然满足，不填 hist_ye。两期对比的 prev 与趋势 hist 同口径，prev=hist 倒数第 2 期
- 三期趋势 + 同业对照（行业基准用 mx/tushare 同行数据计算）；calc.py 可复算 DSO/DIO/DPO/CCC
- 判读规则：
  - CCC 持续拉长 + 收入高增 = **以营运资本换增长**，增长质量打折（成长质量打折的典型情形）
  - CCC 收窄 = 造血能力改善 → 🟢 亮点清单
  - **DPO 双面性**（必须配合第二坐标，单一指标不判）：DPO 拉长 + 货币资金充裕/短债覆盖≥2
    = 对上游议价力 🟢；DPO 拉长 + 短债覆盖 <1.5 = 拖欠供应商 🔴
- 特殊行业注意：白酒等基酒贮存行业的 DIO 天然以「年」计（茅台 DIO≈1400 天），
  CCC 的绝对值无意义，**只看自身趋势与同业差**

**DSO × 收入增速四象限**（应收质量定位，接 redflags #4）

| | 收入↑ | 收入↓ |
|---|---|---|
| **DSO↓** | 最优：真金白银的增长 🟢 | 收缩但回款健康（主动去杠杆）|
| **DSO↑** | 警惕：压货/放宽信用换收入 🟡→🔴 | 恶化：需求与回款双杀 🔴 |

## 二、杜邦三分解

ROE = 净利率 × 总资产周转率 × 权益乘数

- **推荐口径（避免闭合不上）**：摊薄 ROE = 净利率（归母净利 ÷ 营业总收入）
  × 总资产周转率（收入 ÷ 平均总资产，tushare `assets_turn`）× 权益乘数（期末总资产 ÷
  期末归母净资产）。三因子连乘与摊薄 ROE 允许 1~2pct 闭合差（周转率用平均值、乘数用
  期末值所致），报告中注明口径即可，不必强行配平
- 对比本期与上期的三项，判断 ROE 变化由谁驱动
- **质量排序**：净利率驱动 > 周转率驱动 > 杠杆驱动（杠杆驱动的 ROE 提升质量最低）

**贡献归因必须用连环替代（v0.0.12 定案，calc.py `check_dupont` 复算卡口）**

定序「净利率 → 周转率 → 权益乘数」，逐项替换保证三效应加和**恒等于**三因子积的变动：

```
净利率效应 = (m₁−m₀) × t₀ × l₀
周转率效应 = m₁ × (t₁−t₀) × l₀
杠杆效应   = m₁ × t₁ × (l₁ − l₀)
Σ三效应 ≡ (m₁t₁l₁) − (m₀t₀l₀)   （精确闭合，无交叉项）
```

- **口径差必须显式标注**：`closure_gap = ΔROE摊薄 − Δ三因子积`（周转率平均余额口径 vs
  ROE 期末口径所致），落 data.json `derived.dupont.closure_gap`，报告 srcline 如实写出，
  **禁止让「三效应加和 ≈ ΔROE」的假象过关**（中免 2026H1 报告 +1.01+0.46−0.40 ≠ +0.70pct
  的教训——读者会自己加总）
- `driver` = 三效应中 |贡献| 最大者；figtitle 只报主驱动 + 裁决，**不在标题复述全部数字**
- 缺同口径上期（口径断裂等）→ 整块 null 并注明，不降级硬算

**双驱动护栏（v0.0.15，F-09）**：第一、二大 |效应| 之比 `effects_ratio < 1.5` 时
`driver_fragile=true`——报告必须写「双驱动（X/Y）」，禁止单一标签过度引导
（效应量级接近时「主驱动是谁」本身不稳定，标签脆弱性如实标注）。

### 因子级下钻（v0.0.15，F-01/02/03）

三因子各补一层下钻，**子行只放证据、判断只在 figtitle/takeaway**（每因子 ≤1 行）：
全部机械可复算（calc.py 卡口），落 data.json `derived.dupont.*_drill`。

| 因子 | 下钻 | 口径 |
|---|---|---|
| 净利率 | 恒等四项分解：经营（ΔEBIT率）/ 税负（−Δ税率）/ 利息（−Δ财务费用率）/ 少数股东 | `np_at/rev ≡ EBIT/rev − fin_exp/rev − tax/rev − minority/rev`，四效应加和恒等于 Δ净利率；与 <a>S3 净利桥</a> 互证（毛利率/费用率明细在桥里） |
| 总资产周转率 | Δ总资产科目贡献前二 + 聚合份额（应收存货类 vs 产能类） | share 分母=Δ总资产；应收存货堆积=恶化（接排雷），在建/固定资产=产能扩张暂时性摊薄（接 S5 投产时点）；|ΔTA|<1%·TA 时整块 null（总资产未动，定位无意义）；仅两期均提取的科目参与 |
| 权益乘数 | 有息 / 无息拆解 | 有息=短期借款+一年内到期非流动负债+长期借款（含应付债券/租赁负债）；无息=应付账款及票据+合同负债——**不含其他应付款**（schema 无此字段，srcline 声明口径）；无息占总杠杆比 + ΔDFL 供升档判定 |

**质量排序改写（F-02，推翻静态排序）**：原「净利率 > 周转率 > 杠杆」静态排序对无息占款型
公司系统性误判（茅台/格力式预收占款是护城河而非风险）。升级为条件判定——**杠杆效应为
主驱动时先拆有息/无息**：
- 无息占比 > 70% 且 |ΔDFL| < 0.1 → 升档「**话语权型杠杆**」（占款能力=产业链话语权）；
  **阈值为经验起点、随样本校准，只触发提醒级呈现（yellow），永不触发红色否决**
- 有息占比 > 50% → 维持「质量最低」并强制交叉 S7 健康检验（短债覆盖 / 利息保障）
- 杠杆非主驱动 → 升档判定不适用（quality_upgrade=null），拆解数字照常呈现

**扣非口径双版归因（F-04）**：`nonrecurring_share > 20%` 或 |净利率 − 扣非净利率| > 1pct
触发第二版（扣非净利率替换净利率因子重跑连环替代，ROE 用扣非摊薄口径）——
防「含非经的净利率被误读为主业改善」；未触发时单版呈现、不占版面。

### 五年累计归因与因子分位（v0.0.15，方案 A+D，替代五年逐年主驱动表）

逐年标主驱动 = 5 个孤立噪声点（既不能行动也不能证伪）。真正信息在**路径**与**结构**：

- **方案 A 五年累计归因**：ratios hist 首末两期端点间一次连环替代（定序与当期版一致），
  回答「这五年赚钱模式变了没有」。判读：
  - 单因子 |贡献| > 总 ΔROE 的 60% → 该因子为五年主叙事，figtitle 点名
  - 净利率与周转率效应**反向**且合计仍为正 → 标「模式迁移」（如低毛利高周转→高毛利低周转）——
    五年表唯一值得说出口的叙事形态
  - 三因子同向 → 「全面改善/全面恶化」，直接进亮点/风险清单
  - hist < 3 期 → 整块 null 降级两期归因（口径断裂合法）
- **方案 D 因子分位**：当前值在自身五年区间的位置读数 `(rank−1)/(n−1)`——
  n=5 时只有 0/25/50/75/100 五个离散值。**呈现一律用白描读数，不贴「上限区/下限区」
  判断性标签**（v0.0.18 定案：5 期样本贴档位是过度暗示，「第 2 低」≠「下限区」）：
  0→「5 期最低」、25→「5 期中第 2 低」、50→「5 期中居中」、75→「5 期中第 2 高」、
  100→「5 期最高」——徽章只陈述位置，判断写在 takeaway 文字。判读与修复路径联动：
  - 5 期最高：因子已用到自身五年极限 → 修复路径剔除该因子作为假设方向，进 watchlist 盯回落
  - 5 期最低：修复空间所在 → 合法假设方向（「若周转率回到五年中位 → ROE≈x%」（估算））
  - **周期股分位必须挂周期定位解读**（净利率 5 期最高在周期顶部=顶部特征而非经营上限）
- 五年首末两期间发生会计政策变更/并购重组 → 触发既有 period_mismatch 规则时整块 null

## 三、破产风险模型（Altman Z + Ohlson O，谨慎使用）

**两个模型并列互证，禁止综合成单一评分**（「不产出跨维度加权合成分」定案）；报告 s7
并列一行呈现。两模型都是美国样本训练的辅助参考，A 股仅作交叉验证视角。

**Altman Z-Score（制造业经典模型）**

Z = 1.2·X₁ + 1.4·X₂ + 3.3·X₃ + 0.6·X₄ + 1.0·X₅

- X₁ = 营运资金 ÷ 总资产 =（流动资产合计 − 流动负债合计）÷ 总资产
  （schema `balance.total_cur_assets / total_cur_liab`）
- X₂ = 留存收益 ÷ 总资产 =（未分配利润 + 盈余公积）÷ 总资产
  （**禁止用「净资产×0.5」之类顶替**——字段缺失则模型整块不执行，宁可空值不给错值）
- X₃ = EBIT ÷ 总资产（EBIT = 净利润 + 所得税 + 财务费用，复用 X71/X72 口径）
- X₄ = **期末总市值 ÷ 总负债**（`meta.market_cap_cur`，**单位写死：亿元**，与全局一致；
  tushare `daily_basic.total_mv` 是万元，入库前 ÷1e4——市值缺失则 Altman 不执行置 null）
- X₅ = 营业收入 ÷ 总资产（**中期报告先按〇节日化**）
- 判定：Z > 2.99 安全；1.81~2.99 灰色；< 1.81 危险

**Ohlson O-Score（简化六因子，logit 破产概率）**

```
O = −1.32 − 0.407·ln(总资产/亿元) + 6.03·(总负债/总资产) − 1.43·(营运资金/总资产)
    + 0.0757·(流动负债/流动资产) − 1.72·I(总负债>总资产) − 0.521·X6
X6 = (净利润本期 − 净利润上期) ÷ (|本期| + |上期|)
P = 1 ÷ (1 + e^(−O))
```

- 判定：P > 0.5 高；> 0.15 中；否则低
- X6 缺同口径对比期净利润（口径断裂等）→ 整块置 null，不顶替
- ln() 的总资产按**亿元**计（本技能全局单位；该模型对量纲敏感，换单位必须重述常数）

**使用纪律**（两模型共用）

- **口径警示**：系数基于美国样本，A 股仅作辅助参考，报告中必须注明此局限；
  金融/地产不适用（负债结构不同），这两类直接跳过
- **并列呈现规则**：两模型同向 → 可按强度下措辞（如双高危可写「破产风险高」）；
  分歧 → 并列两值 + 一句「模型分歧，均作辅助参考」，**禁止取平均/合成**
- 破产模型是**现状快照**，回答「现在健不健康」；「恶化情景下扛不扛得住」由第九节
  压力情景回答，两者不互相替代

## 四、Beneish 思路（利润操纵，用简化版）

完整 M-Score 八因子（DSRI/GMI/AQI/SGI/DEPI/SGAI/LVGI/TATA）数据量大，
实操用**三因子简化版**：
1. **DSRI 应收指数**：(应收/收入) 本期 ÷ 上期，>1.2 警惕
2. **GMI 毛利率指数**：上期毛利率 ÷ 本期毛利率，>1.1 且收入高增 → 动机+迹象
3. **TATA 应计比率**：(净利润−经营现金流) ÷ 总资产，>0.1 警惕（即 Sloan 应计）

三因子同向恶化时引用完整 M-Score 结论措辞：「存在利润操纵嫌疑，需结合问询函与审计意见核实」。

## 五、现金验证（刘姝威方法）

- **净现比** = 经营现金流净额 ÷ 净利润：>1 优，0.5~1 可接受，<0.5 警惕
- **收现比** = 销售商品收到的现金 ÷ 营业收入（含税口径约 1.13 为正常）：
  <0.9 说明收入在「打白条」
- 两张表对照看：利润表漂亮 + 现金流量表难看 = 最大风险组合

**时序读数（v0.0.12，落 `derived.cash_ts`，calc.py 复算）**——单期净现比可被单年
回款节奏粉饰，5 年纹理才分得出「稳定造血」和「忽高忽低」：

- **净现比时序**：5 期均值 + OCF 为负的年数（`ncr_mean5` / `ncr_neg_years`）
- **FCF 覆盖时序**：FCF = OCF − 资本开支（`cashflow.capex`），5 期 FCF÷归母净利均值
  + FCF 为负的年数（`fcf_to_np_mean5` / `fcf_neg_years`）
- 判读护栏：周期股 OCF 随周期波动，时序读数必须挂第六节周期定位解读；
  **扩张期公司 FCF 常年为负是投资去向问题**（回因素分析看 Capex 落点），不直接判负
- hist <3 期（口径断裂等）→ 整块 null，不硬算

## 六、周期定位（P1-13，Phase 2 用）

用三条线定位公司所处周期阶段，**阶段决定信号如何解读**（同一个信号在不同阶段含义相反）：

| 三线特征 | 阶段 | 信号处理规则 |
|---|---|---|
| 收入增速↑、毛利率↑、资本开支↑ | **上行** | 存货增加=备产（🟢）；在建工程上升=正常扩张；高 Capex 不视为负面 |
| 增速见顶回落、毛利率高位、Capex 仍高 | **顶部** | 存货增加=警惕滞销；逆周期继续扩张=风险（🔴）；关注产能投产时点与需求错配 |
| 收入↓、毛利率↓、Capex 收缩 | **下行** | 净现比恶化容忍度提高；减值计提常见（区分「洗澡」与真实恶化）；关注现金流能否撑过下行 |
| 收入低位企稳、毛利率触底、Capex 冰点 | **底部** | 存货上升=降级为观察（可能是主动备产）；高负债=关注偿付而非盈利；资本开支拐点=先行信号 |

- 判定数据来自 data.json 的 `hist` 数组（Phase 1 已拉 5 期）+ `capex.hist`
- 报告 S1 或核心结论区声明「本报告按【X 阶段】框架解读信号」
- **v0.0.15 起阶段判定必须可核验（F-07）**：三线特征读数（收入增速/毛利率/Capex 增速逐期）
  落 data.json `derived.cycle_evidence`（calc.py 复算）并在 S1 周期定位证据表呈现——
  判定从「无证据声明」变「可核验前提」；判定与三线特征不一致时重写判定，不许硬挂
- **写法规范（v0.0.18）**：判定行只放结论（「上行期（收获段）」一句话），判定依据与
  例外项放 takeaway——禁止把「三线逐线对号 + 不匹配项如何处置」的推理过程写进判定行。
  示范：判定行「上行期（收获段）」；takeaway「收入增速与毛利率同步回升，两线支持上行；
  Capex 连续两期收缩不套档，按扩张收敛后的收获段解读：存货增加按备产读（🟢）、
  资本开支过峰不视为负面、DOL 按经营弹性读」

**成本传导时滞（周期定位配套工具，资源周期/重资产制造必做）**
原材料价格（mx `mx_macro_data`）→ 库存消化周期（DIO 作为传导时滞代理变量）→ 毛利率，
三者形成滞后传导链：
- 大宗已涨但毛利率未跌 → 公司仍在消化低价库存，**毛利率拐点尚未到**（勿过早乐观）
- 大宗已跌但毛利率仍在降 → 消耗高价库存中，**拐点在即**
- 用法：DIO 越长（如 >90 天），传导时滞越久；结合 DIO 与原材料价格走势预判毛利率拐点

## 七、费用投入产出分析（P1-16，增量 ROI 视角）

现有净利润桥把费用只当「拖累项」（Δ费用 = 负贡献）。本节补**投入产出评价**——
诊断**经营效率**而非财务真实性，**不进排雷清单**，作为盈利质量的定性证据并入因素分析。

| 指标 | 公式 | 判读 |
|---|---|---|
| 增量费用效率 | Δ毛利 ÷ Δ期间费用 | >1 = 费用换来更多毛利 🟢；<0.5 且费用率上升 = 效率恶化 🔴 |
| 销售费用获客效率 | Δ收入 ÷ Δ销售费用 | 趋势下降 = 增长越来越贵（增收不增利前兆） |
| 研发投入转化 | 研发费用率 × 新品/新业务收入占比 | 高研发低转化 = 研发悬空（接 text-mining「真布局四问」） |

**费用率上升的三分归因（只惩罚第二种）**：
- **扩张驱动**：费用与收入同步增长 → 中性，不计入负面
- **效率下降**：费用增速 > 收入增速且无对应产出 → 计入负面（效率恶化）
- **结构变化**：渠道/业务模式切换导致 → 需 MD&A 佐证，中性

**与 Phase 7 的闭环**：增收不增利的三层递进诊断——
① 剪刀差检测（收入增速 vs 利润增速）→ ② 费用桥去向（钱花在哪）→ ③ **本节投入产出比评价（花得值不值）**

## 八、数字行为与四线考核检测（P2-22）

盈余管理常表现为「**刚好达标**」。四条线分别对应四种动机，**任一线贴线（实际÷目标 ∈ 95%~105%）
自动进黄色清单**，并在报告中显式指出动机。

| 线 | 阈值特征 | 动机 |
|---|---|---|
| ① 保壳线 | 净利润微利（净利率落 0~3% 收入区间）、ROE 贴 **6.5%** | 规避退市/ST |
| ② 再融资线 | ROE 贴 **10%** | 满足增发/可转债财务门槛 |
| ③ **股权激励考核线** | 实际营收/净利刚好压线达标（95%~105%） | 达标才能行权，管理层有强动机 |
| ④ Q4 突击集中度 | Q4 收入/减值/转固异常集中（见 report-types.md Q4 五项检测） | 年末调节 |

**③ 的取数与量化（最易被忽略、但锚最硬）**：
- 考核目标来自**公开披露的股权激励计划公告**（mx `mx_finance_search_notice` 查
  「股权激励计划 / 考核目标 / 行权条件」；年报「股份支付」附注给摊销金额）
- 必须**同时量化股份支付摊销对利润的影响**——激励本身压低当期利润，
  剔除后才好判断「主业是否真的达标」
- 连续多期刚好达标（如三期都在 100%~103%）= 强冲线嫌疑

**四线检测落表（v0.0.15，F-08）**：四条线的读数/目标/距离/判定落 data.json
`derived.threshold_check` 并在 S2 贴线检测表呈现（Q4 集中度消费 derived.q4 不重复计算）：
- 保壳线/再融资线由 calc.py `--fill` 机械判定（贴线=实际÷目标 ∈ [0.95,1.05]，
  保壳线另需净利率落 0~3% 合取）
- 激励线为取数+判断字段：`target` 取自公告（src 必填），`share_payment` 填本期股份支付
  摊销（未披露填 null）；calc.py 复算 ratio 与 hit；无激励计划时整块 null、
  报告填「—（无股权激励计划）」不许缺席

**Benford 尾数分布（附录级实验指标，慎用）**
- 对收入/费用明细的首位数字做 Benford 分布检验，偏离过大提示人工编造
- **必须标注**：学术性指标、样本量小时误报率高、A 股适用性未经验证
- 仅作为附录观察，**不得单独作为结论依据**，不得进红色清单

## 九、杠杆结构与压力情景（经营杠杆 + 财务杠杆，X71/X72 + 压力测试）

利润波动的两个放大器。回答的问题：**收入或成本小幅波动，会被放大成多大的利润波动**——
配合第六节周期定位，回答「下行期扛不扛得住」。

| 指标 | 公式 | 读法 |
|---|---|---|
| 财务杠杆 DFL | (净利润+所得税+财务费用) ÷ (净利润+所得税) = EBIT ÷ 税前利润 | 越接近 1 利息负担越轻；>1.5 = 税前利润被利息明显侵蚀 |
| 经营杠杆 DOL | (EBIT+折旧摊销) ÷ EBIT = EBITDA ÷ EBIT | 越高固定成本越重：收入小降 → 利润大降 |

- 字段：np_total / income_tax / fin_exp / dep_amort（calc.py 内置复算 cur 与 hist 逐期）
- **DOL 的正确用法不是比大小，是看方向 + 周期位置**：上行期高 DOL 是利润弹性（🟢），
  下行期高 DOL 是利润陷阱（🔴）——同一数值在不同阶段含义相反，落到周期定位后再定性
- DFL 与「有息负债率/利息保障倍数」交叉看：DFL 高但利息保障倍数也高 = 借得便宜，中性；
  DFL 高 + 保障倍数 <2× = 债务结构危险
- 阈值仅作锚点：DFL >1.5、DOL >2 进入「需解释」；两杠杆同升 = 利润波动被双端放大，
  列入 watchlist 跟踪

**流动性压力情景（v0.0.12，落 `derived.stress`，calc.py 复算）**——把杠杆从描述性数字
变成推演工具，回答「收入跌两成，这公司还活不活」。三档收入冲击 p = 10% / 20% / 30%：

```
受压 EBIT   = EBIT × (1 − p × DOL)          （DOL 即公司真实成本结构的度量，不拍脑袋假设固定成本占比）
受压税前利润 = 受压 EBIT − 财务费用           （财务费用视为刚性；可为负，负值=净利息收入继续贡献）
受压净利润   = 受压税前 × (1 − 有效税率)     （受压税前 ≤0 时不再计税收抵免，保守）
受压短债覆盖 = (货币资金 + OCF×(1−p)) ÷ (短期借款+一年内到期)   （OCF 同比例收缩为粗近似，注明）
```

- **判级纪律**：p=10% 受压净利润 < 0 **不直接 🔴**，进 watchlist 加「安全垫薄」措辞；
  周期底部公司天然敏感——结论必须挂第六节周期定位解读，避免误伤
- **估算口径**：压力情景是「情景推演、非预测」，报告呈现时带 est 徽章；
  本量利传导是线性近似（DOL 随收入水平变化），只作量级判断
