# 因素分析操作手册（factor-analysis）

> Phase 4 专用。目标：把「收入/成本/净利润/经营现金流变了多少」拆成「各因素各贡献多少」，
> 让结论从「同比增长 12%」升级为「增长 12% 中，量贡献 6pct、价贡献 3pct、结构贡献 3pct」。

## 一、收入变化：量价结构三因素分解（首选）

**能拆量价的多产品公司必拆三因素**，不做量价二合一。结构效应（mix effect）常是
第一驱动且性质独立：同价同量、只是高毛利产品占比上升，就是最高质量的增长
（茅台非标占比提升、苹果 Pro 系列占比提升都属此类）。两因素拆法会把它塞进
「价效应」，得出「提价驱动增长」的错误结论。

数据源：年报 MD&A「主要产品产销存」表（分产品销量与均价），落 data.json 的
`statements.income.by_segment`（`vol_cur`/`vol_prev`/`price_cur`/`price_prev`）。

```
Δ收入 = 量效应 + 价效应 + 结构效应(mix effect)

基期加权均价 P̄₀ = 基期总收入 ÷ 基期总量

量效应   = Σ Δ量ᵢ × P̄₀
结构效应 = Σ Δ量ᵢ × (基期价ᵢ − P̄₀)
价效应   = Σ 本期量ᵢ × Δ价ᵢ
```

（i 为各产品/分部。量效应 + 结构效应 = Σ Δ量ᵢ × 基期价ᵢ，正是两因素法的量贡献；
拆开的意义在于把「总量做大」与「往高价值产品倾斜」分离——后者才决定毛利率走向）

- 三效应之和必须 = Δ收入。写入 `derived.rev_factors.volume/price/mix`（亿元），
  calc.py 桥闭合校验项 `bridge.rev` 重算，不平即 FAIL
- **P̄₀ 的可比性前提**：加权均价只在「计量单位可比」的产品组内成立（吨 vs 吨）。
  业务含服务/会员费/授权费等无实物量口径时，按产品组分别拆三因素，组间不合并
  求 P̄₀，否则结构效应会被单位错配污染
- 报告呈现：桥式表**必须三行**（基期收入 → +量效应 → +价效应 → +结构效应 →
  本期收入），多产品公司不得压回量价两行
- **结构效应判读**：
  - 结构升级（高毛利产品放量，结构效应为正且占比可观）→ 毛利率结构性改善，
    最高质量的增长驱动，直接进亮点清单
  - 结构恶化（低毛利产品放量）→「增收不增利」的结构性根源，接费用 ROI 分析
    （`derived.ratios.incr_expense_eff` = Δ毛利 ÷ Δ期间费用），并入盈利质量的定性判断
- 量价解读纪律：
  - 量增价跌 = 以价换量，看毛利率能否扛住
  - 价增量平 = 提价能力/结构升级，最高质量
  - 量价齐跌 = 需求出问题，去 MD&A 找解释
- **降级路径**：报告未披露量价时改用第二节的分部收入桥，`derived.rev_factors`
  三项留空（calc.py 记 SKIP，不判失败），报告中如实标注
  「报告未披露量价，降级为分部桥」

## 二、收入变化：结构桥（无量价数据时）

用分产品/分地区/分客户收入表（财务报告附注「营业收入和营业成本」）：

```
Δ收入 = Σ(各分部本期收入 − 基期收入)
贡献度 = 单项变化 ÷ 总变化
```

- 找出贡献前二的分部，回答「增长主要靠哪条线」
- 同时看**集中度变化**：是否从多点开花变成单点依赖

## 三、成本变化：构成拆解

用成本分析表（年报 MD&A「成本分析」节，分行业/分产品的成本构成）：

```
Δ成本 = Δ直接材料 + Δ直接人工 + Δ折旧摊销 + Δ能源 + Δ其他
```

- 结合**单位成本**与原材料价格走势（mx `mx_macro_data` 查对应大宗品种）
  判断成本变化是「量驱动」还是「价格驱动」
- 成本增幅 < 收入增幅 → 毛利率改善，找原因：原材料降价？规模效应？结构升级？

## 四、净利润桥（每期必做）

从营业收入到归母净利润逐层算同比贡献额：

```
基期归母净利
+ Δ收入 × 基期毛利率          （收入规模贡献）
+ Δ毛利率 × 本期收入          （毛利率贡献）
− Δ税金及附加                 （消费税/城建附加，酒类、烟草等高税负行业必拆）
− Δ销售费用 − Δ管理费用 − Δ研发费用 − Δ财务费用   （费用拖累）
− Δ资产/信用减值损失          （减值拖累）
+ Δ投资收益 + Δ公允价值变动    （非经营贡献）
+ Δ其他收益（政府补助等）
− Δ所得税费用                 （税率影响，注意优惠资质变化）
± 少数股东损益变化
= 本期归母净利
```

- 每项贡献额从利润表同比直接算出，标注正负与金额
- **必须回答**：本期利润变化的第一驱动是什么？（毛利改善 / 费用压缩 / 减值减少 /
  非经常性损益 / 基数效应）
- 非经营性贡献占比 >30% 时降格表述：「利润增长主要由非经常项驱动，持续性存疑」
- 净利桥解释「利润怎么来的」，**另见第五节调节桥**（解释「利润为什么没变成现金」）

## 五、净利 → 经营现金流调节桥（间接法，每期必做）

与第四节净利桥并列的第二座桥：净利桥回答「利润怎么来的」，调节桥回答
「利润为什么没变成现金」。两桥起点不同——净利桥终点是归母净利，调节桥起点是
**净利润（含少数股东）**，别混。

```
净利润(含少数股东)
→ +折旧摊销
→ +资产减值
→ ±递延所得税
→ −Δ经营性应收增加
→ −Δ存货增加
→ +Δ经营性应付增加
→ ±其他
= 经营活动现金流量净额
```

- **数据源**：年报「现金流量表补充资料」（附注末段，A股强制披露），逐行搬进
  `derived.ocf_bridge`。首项「净利润」填**水平值**，其余为调节项，Σ 必须 = OCF，
  calc.py 桥闭合校验项 `bridge.ocf` 重算
- **item 命名**：按补充资料原行名照录，schema 骨架里的八项是归并模板，可增行可细化
  （如「减值」拆成信用减值/资产减值，「财务费用」「投资损失」单列）。calc.py 只对
  delta 求和，不认 item 名——但每一行都必须能在补充资料里找到原文对应，缺行会导致
  桥不闭合而暴露为 FAIL，不要靠「其他」凑平
- **符号约定**：调节项按补充资料原符号录入，即已是现金流方向——应收增加记负、
  折旧摊销记正，不做二次取负。桥内各项 delta 直接相加即得 OCF
- 呈现规范与净利桥一致：桥式表 + 一句话「主吞噬项」结论，格式
  「利润 X 亿，其中被应收吞掉 a 亿、被存货吞掉 b 亿，折旧回血 c 亿」
- **配套指标 营运资本现金吞噬额**（写入 `derived.wc_devour.amount`，
  占净利润比写 `derived.wc_devour.share_of_np`）：

```
吞噬额 = −(Δ应收 + Δ存货 − Δ应付 − Δ其他)
```

（ΔX 取资产负债表口径的**余额增加额**，增加为正。此式恒等于调节桥内四项营运资本
delta 之和：算得为负 = 营运资本净吞现金，吞噬额取其绝对值；算得为正 = 营运资本
释放现金。`wc_devour.amount` 统一填正数表示被吞掉的金额。`share_of_np` 的分母用
**净利润（含少数股东）**，与调节桥起点自洽；跨到 `redflags.md` 第 3 条时该条用归母
口径，两者差异如实标注）

  - 吞噬额 > 净利润 50% → 盈利质量警示，直接为 `redflags.md` 第 3 条「净现比
    长期异常」提供量化依据与归因
  - 吞噬额连续多期存在且逐年递增 → 增长靠营运资本垫资，去应收账龄（`notes.ar_aging`）
    与存货构成（`notes.inventory_mix`）找具体堵点
- **与净现比的分工**：净现比（结果层，`derived.ratios.net_cash_ratio`）告诉你
  「利润与现金不匹配」；调节桥（过程层）告诉你「差在哪一项、各吞了多少」
  ——前者出结论，后者出证据，报告里两者配套使用

## 六、收入-毛利业务组合四象限（多分部公司必做）

回答「销售额最高 ≠ 利润贡献最高」：只看收入排名会把低毛利分部当成主力，本节也是
「增收不增利」的结构定位工具。数据源与第一节同表：`statements.income.by_segment`
的 `rev_cur`/`rev_prev`/`cost_cur`/`cost_prev`，逐分部算：

```
gᵢ  = rev_curᵢ ÷ rev_prevᵢ − 1                        分部收入增速
mᵢ  = 1 − cost_curᵢ ÷ rev_curᵢ                        分部毛利率
Δmᵢ = mᵢ(本期) − mᵢ(基期)                             毛利率同比变化
wᵢ  = rev_curᵢ ÷ Σrev_cur                             收入占比
pᵢ  = (rev_curᵢ − cost_curᵢ) ÷ Σ(rev_cur − cost_cur)   毛利贡献占比
```

**（1）象限边界：原点取公司整体，不取 0**

```
x₀ = Σrev_cur ÷ Σrev_prev − 1     整体收入增速
y₀ = 1 − Σcost_cur ÷ Σrev_cur     整体毛利率
```

以 0 为原点只能看出「涨了没、赚不赚」，看不出**相对结构**。只有毛利率高于整体的
分部才是结构效应的正贡献源；整体毛利率下滑的年份，「毛利率 30%、还在增长」的分部
在 0 原点下看着像明星，放到整体原点才现原形。

y 轴两种口径，按用途选：
- y = mᵢ（毛利率水平）→ 看当前谁在赚钱，用于资源再分配判断
- y = Δmᵢ（毛利率同比变化）→ 看谁在变好/变坏，用于拐点识别
- `rev_prev`/`cost_prev` 为 null 时降级为水平口径，报告中如实标注

**（2）四象限判读**

| 象限 | 位置 | 判读 | 动作 |
|---|---|---|---|
| **明星** | gᵢ>x₀, mᵢ>y₀ | 增长快且毛利率高于整体，结构效应的正贡献源 | 资源倾斜；对照 `notes.cip_projects` 与 capacity 看产能/渠道是否跟得上 |
| **以量换价** | gᵢ>x₀, mᵢ<y₀ | 靠低毛利放量换增长，「增收不增利」的结构来源 | 先看 Δmᵢ 方向：Δmᵢ≥0 = 规模效应在改善、可容忍；Δmᵢ<0 = 真金白银的利润侵蚀，进风险清单 |
| **现金牛/潜力** | gᵢ<x₀, mᵢ>y₀ | 高毛利但没增长 | 分「市场问题」与「投入不足」：满产 = 需求到顶，收获现金；产能利用率低 = 投入不足，查 MD&A 与产能表 |
| **衰退** | gᵢ<x₀, mᵢ<y₀ | 双低，拖累整体 | 评估退出/收缩；盯减值（商誉、固定资产）与关停一次性损失 |

四象限不必都有人。若只有「以量换价」和「衰退」两个象限有分部，整体必然是增收不增利
或量价齐跌，直接把这句话写成结论首句。

**（3）双排名表（配套输出物，必出）**

一张两列排名的表：**收入占比排名** vs **毛利贡献占比排名**，按毛利贡献占比降序排。

```
错位度 = |收入占比排名 − 毛利贡献占比排名|
占比差 = pᵢ − wᵢ
```

- **错位度 ≥ 2**，或 **占比差 ≤ −5pct**（毛利贡献占比比收入占比低 5 个百分点以上）
  → 资源错配信号：该分部占了销售资源却不出利润
- 收入排名第一、毛利贡献排名非第一的分部，报告里**不准**再叫「主力增长引擎」，
  只能写「收入第一、利润第 N」
- 这张表就是「收入涨了利润没涨」最直观的证据，比散点图更适合放正文；散点图可入
  附录或省略，象限归属用文字点名即可

**（4）与既有模块的联动**

- **与第一节结构效应互验**：结构效应为正 ⇒ 放量的分部应落在「明星」象限。两处矛盾
  时先别改结论，按序排查：①口径差（三因素按产品、四象限按分部/地区，两套表切分
  不一致）②分部间内部交易未抵销 ③成本分摊假设或折旧重分配变更导致毛利率不可比。
  三项都排除后，才写「结构效应来源存疑」
- **与「增收不增利」判定闭环**：Δ收入>0 且 Δ毛利率<0 → 第四节净利桥定位费用/税金
  去向 → 本节定位到是哪个分部把毛利率拉下来（「以量换价」象限中 mᵢ 最低者）
  → 结论句式「增收不增利来自 {分部}，收入占比 a%、毛利贡献占比仅 b%、毛利率 c%，
  低于整体 d 个百分点」
- 落库：可内联在 `derived` 下（键名 `segment_quadrant`，extraction-schema.md 骨架
  待补）；不落库时按本节公式现算，不得凭印象指派象限

**（5）裁剪规则**

`by_segment` 只有一条，或各条实为同一业务的地区拆解且毛利率差 < 1pct 的单一产品
公司 → 本节整节裁剪，报告中**置灰保留标题并标注「本报告类型不适用」**，不删标题、
不留空白（对齐「裁剪不消失」纪律）。

## 七、连环替代法（需要严谨归因时）

多因素乘积关系（如 ROE = 净利率 × 周转率 × 杠杆）的归因：

```
以基期 A₀B₀C₀ 为起点，逐因素替换为本期值：
因素A贡献 = A₁B₀C₀ − A₀B₀C₀
因素B贡献 = A₁B₁C₀ − A₁B₀C₀
因素C贡献 = A₁B₁C₁ − A₁B₁C₀
```

- 替代顺序影响分摊，常规顺序：先数量后价格、先经营后财务
- 用于杜邦分解的归因呈现

## 八、呈现规范

1. 一律用**桥式表**：起点 → 各因素（+绿/−红）→ 终点，金额与占比如实标注
2. 每个桥配一句话结论，格式「ΔX = a（因素1）+ b（因素2）+ c（因素3），主驱动是因素N」
3. 数据缺口如实声明：「报告未披露量价拆分，改用分部收入桥」
4. 因素分析只解释**本期 vs 上期**，不做远期预测
5. 多分部公司，第六节的双排名表与随之得出的象限归属必须同时出现，不得只给收入排名
