# 文字部分分析框架（text-mining）

> Phase 5 专用。前提认知：**年报的定性章节是管理层主动选择的信息披露**——写什么、
> 不写什么、怎么写，本身就是信号。分析目标：还原管理层想让市场相信的叙事，
> 并用财务数据检验叙事的真实性。

## 一、MD&A 三层读法

1. **表层**：管理层怎么说这一年（经营回顾的叙事主线）
2. **里层**：钱花在哪印证话（资本开支/研发/在建工程与宣称方向是否一致）
3. **底层**：什么话变了（与上期对比的措辞漂移）

## 二、措辞对比法（有上期报告时必做）

逐节对比本期与上期 MD&A / 董事长致辞 / 未来展望：

| 变化类型 | 示例 | 解读 |
|---|---|---|
| 新增强调 | 首次出现「AI」「出海」「第二增长曲线」 | 战略转向信号，去在建工程/研发找证据 |
| 删除弱化 | 上期的主力业务本期篇幅骤减 | 该业务可能边缘化或出问题 |
| 语气弱化 | 「快速增长」→「稳健发展」→「承压前行」 | 景气度/信心下行轨迹 |
| 目标模糊化 | 上期给量化目标，本期只剩方向性表述 | 管理层自己对前景没底 |
| 风险提示新增 | 新增「价格战」「应收账款回收」等条目 | 管理层最担心的事，优先级最高的真实风险 |

操作：用 Grep 在两期 md 中定位同名章节，提取关键词清单做差集对比。

**语气档位词表（T7 可复现量化，v0.0.6 起）**

「语气弱化」此前靠语感判定，不可复现。用词表把语气量化为四档词频——同一文本
两次跑结果必然一致；跨期对比 = **档位迁移 + 各档词集合差集**：

| 档位 | 标志词（财报语境，含通用词典缺失词） | 解读 |
|---|---|---|
| 强（+2） | 强劲增长 / 大幅增长 / 快速增长 / 突破 / 创新高 / 历史新高 / 翻番 / 跨越式 | 景气上行或自我表扬 |
| 稳（+1） | 稳健增长 / 稳步提升 / 稳中有进 / 持续改善 / 向好 / 韧性 / 巩固 | 中性偏正 |
| 弱（-1） | 总体平稳 / 基本持平 / 小幅增长 / 增速放缓 / 低位运行 / 平稳发展 | 降档前兆 |
| 压（-2） | 承压 / 承压前行 / 下行压力 / 不及预期 / 回落 / 下滑 / 收缩 / 严峻 / 挑战加大 | 困难明示 |

用法（有上期报告时必做）：
1. 两期同名章节文本分别 Grep 计数四档词频 → **档位迁移**（如 强→稳 = 降一档）
2. 各档词集合取**差集** → 新增/消失的具体措辞清单（「上期『快速增长』本期改『稳健发展』」）
3. 极性比 =（强+稳词频）÷（弱+压词频），两期对比方向
4. 输出形态：「语气档位：稳(+1) → 弱(-1)，标志性迁移：快速增长→平稳发展（3 处）」——
   **禁止「感觉语气变谨慎」式无词表依据的表述**

**外部参考词表（可选加成，不内置）**：姜富伟、孟令超、唐国豪《媒体文本情绪与股票回报
预测》（《经济学(季刊)》2021(4)）随附中文金融情感词典（负面 5,890 词 + 正面 3,338 词，
仓库 MengLingchao/Chinese_financial_sentiment_dictionary）。**无 LICENSE 文件，不可随
技能再分发**——需要全量极性统计时运行时从 raw.githubusercontent.com 拉取 xlsx 并清洗
词尾换行符，拉取失败降级为本节自有词表。注意其语料为财经媒体文本，「承压 / 不及预期」
等年报高频词缺失（前置调研实测），**本节自有词表优先**。

**只有一期报告时的降级路径**：改用三个替代锚点——① 本期报告内嵌的上期表述
（「较上年同期」「去年」）；② 期后公告与最新季报（看叙事是否延续）；③ 外部研报
叙事对比（mx_finance_search_news）。降级时注明「未取得上期报告，对比精度受限」。

## 三、热门赛道重合度分析

1. 提取公司宣称的发力方向（MD&A「未来展望」「核心竞争力」节的关键词）
2. 对照当下热门概念板块：tushare `dc_index`（东财概念板块行情）、`ths_index` /
   `dc_hot` / `ths_hot`（热榜），看宣称方向与哪些热门赛道重合
3. **真布局 vs 蹭热点判定**（四问）：
   - 有资本开支吗？（在建工程/购建固定资产现金流投向该方向）
   - 有产能/订单吗？（产销数据、合同负债、中标公告）
   - 有研发投入吗？（研发项目明细中该方向的课题）
   - 有收入贡献吗？（分部收入中能否看到）
   四问皆无 = 蹭热点，报告中直说；有两项以上证据 = 真布局
4. **重点宣称数字给行业坐标**：管理层点名的核心规模/份额数字（如「智算总规模 X EFLOPS」），
   只引用数字没有意义，必须补三个坐标：① 同行对比（2~3 家可比公司同口径数字，标注口径与
   时点差异）；② 行业占比（全国/全球盘子多大、公司占几成）；③ 口径说明（自建还是含租赁、
   什么精度口径、什么时点）。三个坐标凑不齐就直说「该口径缺乏可比基准」，不许只搬运管理层
   数字。数据来源：同行定期报告、行业主管部门口径（如工信部）、权威财经媒体交叉。

## 四、隐晦信号清单

- **风险提示章节**：新增条目 > 保留条目 > 套话条目，按此权重读
- **经营目标**：量化目标（收入指引）是有承诺的管理层；只讲方向不讲数 = 谨慎解读
- **大额分红 + 再融资并存**：可能大股东套现或补血，看控股股东质押率佐证
- **「择机」「适时」「视情况」**：计划类措辞里的拖延信号
- **会计估计变更**：折旧年限延长、坏账计提比例下降 = 利润调节动作，
  去附注找金额影响并计入排雷
- **审计报告关键审计事项**：审计师最费力的科目 = 最有水分的嫌疑科目
- **该写而没写**：行业人人皆知的痛点（批价、库存、价格战……）在风险提示中缺席，
  缺席本身就是信号——管理层选择不谈的事往往是最重要的事

## 五、外部印证

- mx `mx_finance_search_notice`：问询函、监管函、处罚、诉讼公告
- mx `mx_finance_search_news`：卖方研报叙事 vs 公司叙事的差异
  （公司说得天花乱坠而研报保守，或反之，都是信息）
- 交易所互动平台问答（tushare `irm_qa_sh` / `irm_qa_sz`）：投资者追问什么、
  公司回避什么

## 六、输出规范

文字分析的结论必须落到三类判断之一：
1. **叙事与财务一致**（说的话有钱印证）→ 加分
2. **叙事超前于财务**（说了还没投/投了还没产出）→ 观察项，标明跟踪点
3. **叙事与财务背离**（说要发力但钱在撤）→ 风险项，进排雷清单

**三问落地（v0.0.6 T11，与 redflags.md 三问范式同一框架）**：三类判断的结论句必须回答——
① **经营上发生了什么**（叙事与数字对照出的事实，一句话）；
② **最可能的解释 + 区分证据**（禁止「一方面…另一方面…」并列——如「背离」必须写明
最可能是「战略放弃该方向」还是「蹭热点」，依据是资本开支/研发/订单哪个锚点）；
③ **下期看什么验证**（叙事对应的可观察锚点：在建工程转固、研发项目结项、订单公告——
候选进 watchlist）。写不出②的区分证据 = 分析没做完，不许只摆「叙事与财务存在差距」。

## 七、断言-验证矩阵（文字验证数字）

> 前六节回答「管理层在说什么」；本节回答「他说的每一句能不能被数字验真」——这是
> 文字分析与数字勾稽的接合点。执行位置：Phase 5 末段，与 Phase 4 因素分析消费同一
> 批数据（`derived.rev_factors` / `statements.income.by_segment` /
> `derived.np_bridge`）。铁律：**三态判定必须有数字依据，禁止「感觉管理层说得对」**
> ——写不出数字的只能判 ❓，不许判 ✅。

**F1-A 断言抽取**：只抽**因果解释型**句子，不抽描述型。锚点词「主要系」「主要原因
是」「主要由于」「得益于」「受…影响」「同比…主要是」。逐条结构化为断言记录：

| 字段 | 填写要求 |
|---|---|
| 断言 | 管理层原话（可截句），保留原措辞，不转述 |
| 涉及科目 | 收入/成本/毛利率/费用/现金流，可多选 |
| 管理层归因 | 原话归因到哪个驱动因素，不替他推 |
| 出处 | 章节名 + 页码，格式同 data.json 的 `src` |

抽取量参照：一份年报 MD&A 的因果解释通常 5~15 条；>20 条时优先覆盖收入、毛利率、
现金流三类，其余列入「未验证」，不自造结论。

**F1-B 逐条数字检验（三态）**：数据只从 data.json 取，禁止对 md 原文直读直写。
按归因类型选用检验式：

| 归因类型 | 典型原话 | 检验式 |
|---|---|---|
| 量驱动 | 「主要系 A 产品放量」 | 该分部 Δ量贡献 ≥ Δ收入 的 50%（`rev_factors.volume`） |
| 价驱动 | 「提价带动收入增长」 | Δ价ᵢ ≥ 0；量增价跌却说提价 → 矛盾 |
| 结构驱动 | 「产品结构优化」 | `rev_factors.mix` > 0 且高毛利分部占比提升 |
| 成本驱动 | 「毛利率下降主要系原材料涨价」 | 成本构成中原材料**金额与占比同升**；占比降 → 矛盾 |
| 费用驱动 | 「费用管控成效显著」 | 费用率降**且**绝对额未增；靠压缩必要投入 → 存疑 |

- ✅ **通过**：数字支持该归因。判定语必须带数字，如「分部 A 收入 +X 亿，量效应
  +Y 亿（占 62%），与『销量增长』一致」
- ❌ **不成立**：数字与原话矛盾。**自动进风险清单**——写 data.json `signals` 条目
  （`level:"r"`、`evidence` = 原句 + 反证数字、`source` = 章节/页码），并作为
  `redflags.md` 相应信号的定性证据（归因不实与第 4/5 条并用）
- ❓ **无法验证**：披露不足。**必须写明缺什么**（缺量价 / 缺成本构成 / 缺分部口径），
  并给替代锚点（外部研报、大宗价格、同业）；写不出缺口 = 没做，不是无法验证

判定纪律：① 一条断言含多个检验点，任一 ❌ 即整条 ❌，不做「部分成立」和稀泥；
② 方向相反（说涨实跌）→ ❌，方向对但强度不符（说大涨实微增）→ ✅ 并标注
「归因方向成立、强度不符」，进观察项；③ 反证数字必须能回到 data.json 叶子
（含 `src`），回不到的不计入检验。

**F2 解释缺口清单**：扫描 `statements` 核心科目与 `notes` 明细，筛出变动幅度超过
30% 的项，与 F1-A 的断言列表对照：

```
变动 > 30% 的科目清单 − 已被 MD&A 解释的科目 = 未解释清单
```

输出三栏：科目 | 本期/上期金额与幅度 | 状态。状态三值——未提及 / 提了但无归因 /
归因与数据不符。前两类写 `signals` 条目（`level:"y"`）；第三类已在 F1-B 判 ❌，
此处只做索引不重复立案。

- 这是第四节「该写而没写」在数字侧的镜像：**数字大动而文字不解释，本身就是信号**。
  两处分工：第四节看风险提示章该有的条目缺席，本节看金额该有的解释缺席
- 幅度 = |本期 − 上期| ÷ |上期|；上期为 0 或 null 的科目改用绝对额门槛（该科目
  占收入 > 5%），避免小基数误报（沿用 `redflags.md` 第 4 条的小基数纪律）

**F3 指引兑现率**（需上期报告）：取上期「经营计划/未来展望」节，与第二节措辞对比
共用同一批章节锚点，取数一次两用。逐条对账并留档：

| 字段 | 填写规则 |
|---|---|
| 目标期 | 上期报告所指引的年度 |
| 上期原话 | 量化目标照抄，含口径与单位 |
| 目标类型 | 量化（收入/利润/产能数字）/ 半量化（「两位数增长」）/ 方向性 |
| 本期实际 | data.json 对应科目的 `cur` 值 |
| 达成判定 | ✅ 达成 / ⚠️ 接近（偏差 ≤10%）/ ❌ 未达成 |
| 未达成归因 | 本期报告是否解释落差（接 F2） |

- **兑现率 = ✅ 条数 ÷ 可量化目标条数**；方向性目标不计入分母，单列统计
- 连续 2 期 ❌ → 指引可信度降级：本期量化目标在报告中标注「该管理层上期目标未
  达成，本期指引打折看」
- 本期目标解读沿用第四节：给量化目标 = 强承诺，与本期实际一起判亮点/风险；只给
  方向 = 谨慎解读。本节只做**量化追踪**，不替管理层解释
- 上期目标含糊到无法取数时如实填 ❓ 并注明「上期未给定可量化目标」——它本身就是
  第四节「目标模糊化」的印证

**呈现规范（模板 S4 断言验证表）**：四列，逐条断言一行。

| 断言 | 数据检验 | 三态 | 出处 |
|---|---|---|---|
| 收入增长主要系 A 产品放量 | A 收入 +X 亿，量效应 +Y 亿（62%） | ✅ 通过 | MD&A P42 |
| 毛利率下降主要系原材料涨价 | 原材料成本 −Z 亿，占成本比 −3pct | ❌ 不成立 | MD&A P43 |
| 新业务贡献显著收入 | 分部表未单列该业务 | ❓ 缺分部收入口径 | MD&A P45 |

1. 「数据检验」列必须出现数字与算式，禁止「有数据支持」这类空话
2. ❌ 条目必须同时出现在正文风险清单，❓ 条目必须同时出现在数据缺口声明，
   不允许只躺在表格里
3. 表下汇总一行：「共 N 条断言：✅ a / ❌ b / ❓ c；未解释的大幅变动 d 项；
   指引兑现率 e%」，该行同时进报告摘要页
4. 三态映射到第六节输出规范：✅ → 第 1 类「叙事与财务一致」；❌ → 第 3 类
   「叙事与财务背离」（风险项）；❓ **不等于**第 2 类「叙事超前于财务」——❓ 是
   披露不足，第 2 类是已投入未产出，报告中必须分开表述
